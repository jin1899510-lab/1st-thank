# 양재차앤박피부과의원 작성 지침 (다음 원고부터 적용)

출처: 네이버 플레이스 (2026-10-21 사용자 제공), 건강보험심사평가원 진료과목별 전문의 정보

## 강조할 강점: 피부과 전문의 진료
- 확인된 사실: 피부과 전문의 3명 (심평원 기준), 박연호 피부과전문의
- 원고마다 아래 자리에 자연스럽게 넣는다.
  1. 도입 인사: "피부과 전문의가 진료하는 양재차앤박피부과의원입니다."
  2. 진료 섹션 첫 문장: "양재차앤박피부과의원은 피부과 전문의 3인이 진료합니다." + 진단·판단 주체를 "피부과 전문의"로 명시
  3. 셀프 체크·구별법 뒤: "비슷해 보이는 피부 질환이 많아 피부과 전문의의 진찰로 확인하시기 바랍니다."
  4. 병원 정보 박스: `의료진 : 피부과 전문의 3인` 줄
  5. 태그: #피부과전문의 #양재피부과전문의
- 의료진 이름은 박연호 원장만 확인됨. 다른 원장 이름은 병원 확인 전까지 쓰지 않는다. 의료진 수는 게시 시점에 심평원 정보로 다시 확인한다.

## 심의 기준 안에서 강조하는 법
- 쓸 수 있음: "피부과 전문의 3인 진료", "피부과 전문의가 직접 진찰", 전문의 자격(사실)
- 쓰지 않음: "일반의와 다르게", "전문의만이 할 수 있는" 같은 다른 의료인과의 비교·비방, "최고 전문의", "OO 분야 권위자", 검증 안 된 경력·학회 직함, 전문의 수를 우수성의 근거로 내세우는 표현
- 전문의를 강조해도 효과 보장으로 이어지지 않게 쓴다 ("전문의가 진료하니 확실히 낫습니다" 금지).
- 페이지 표기: byline_sub는 "피부과 전문의 진료 · 피부 건강 정보" (칼럼·기고 형태로 보이지 않게)
