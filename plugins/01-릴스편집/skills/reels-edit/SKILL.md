# 릴스 편집 → 캡컷

## 0. 분석기 「릴스 만들기」에서 온 요청
- 분석기 화면(02-인스타분석 `web_app.py`)에서 원고 + 사진·영상을 넣으면 `<고객설정>/릴스제작/<업체>/<날짜>/` 에
  `원고.txt`, `제작옵션.json`(길이·목소리·배경음악·후킹·사진 길이·source), `소스목록.json`, `sheets/`, `제작요청.md` 가 생긴다
  (`scripts/prepare_sources.py`).
- 사진은 이미 9:16 세로 영상(천천히 확대)으로 바뀌어 `<소스폴더>/릴스_사진영상/` 에 있다. plan `media` 에는 사진 대신
  `소스목록.json` 의 `clip`(rel·local·1080×1920·길이)을 넣는다. 영상은 원본 그대로.
- `sheets/` 사진을 직접 보고 원고 줄마다 장면을 고른다. 원고의 `[자막]` 줄은 나레이션 없이 화면 글자로만.
- 목소리 `hyuk` = ZJCNdZEjYwkOElxugmW2, `random` = 편마다 다른 한국어 목소리, `none` = 나레이션 없음.
- plan.json 은 그 폴더에 쓰고, 마지막 설치는 이 PC에서 바로 `install_capcut.py <출력폴더> --source <제작옵션.source>`.

## 1. 촬영 영상 파악
- 작업 페이지 4번에 올라온 파일(`media` 목록)을 받는다. 20MB가 넘는 파일은 작은 사본이며,
  사본 앞부분에 멈춘 화면이 있으면(ffmpeg freezedetect) 원본 시간 = 사본 시간 − 차이로 보정한다.
- 파일마다 0.7초 간격 사진을 직접 보고 무엇이 찍혔는지 적는다. 위스퍼로 말을 확인해
  쓸 수 있는 현장 소리(리액션)와 지워야 할 대화(사적인 이야기)를 나눈다.
- 원고 장면과 맞춰 보고, 찍히지 않은 내용은 모션그래픽 카드로 채운다.
  같은 장면을 연달아 쓰지 말고 카드·다른 각도로 끊는다.

## 2. 편집 계획(plan.json)
- 형식은 `scripts/build_capcut.py` 맨 위 설명.
- **업체 하나 = 캡컷 프로젝트 하나, 편 하나 = 타임라인 하나.** plan 에 `store`(업체 이름 = 프로젝트 이름),
  `episode`(편 번호), `title`(타임라인 제목)을 적는다 → 타임라인 이름 "01 제목".
- 길이는 25~30초. 효과는 무료 항목만 (pycapcut 메타데이터에서 두 번째 값이 False).
- 원고 스타일의 구조(제목 방식, 장면 길이, 음성 형식)를 지킨다.
- 모션그래픽 카드는 **30초마다 최대 4개**. 넘치면 내용을 한 카드에 합치고, 남는 시간은 아직 안 쓴 촬영 구간으로 채운다 (build_capcut.py 가 넘치면 멈춘다).

## 3. 만들기
1. `python3 scripts/render_cards.py plan.json 카드폴더` — Remotion 카드 (가격·목록·숫자·마무리)
2. `python3 scripts/build_capcut.py plan.json 카드폴더 출력폴더` — 캡컷 초안 (원본 경로는 자리표시)
   배경음악: 일레븐랩스 음악(eleven_music, 가사 없음, 30초)을 만들어 plan `music.file` 에 적는다.
   나레이션이 있으면 volume 0.3 / duck 0.1, 없으면 volume 0.6 / duck 0.2 (현장 소리 구간만 줄임).
3. 저화질 미리보기 영상과 컷 스토리보드를 만들어 직접 확인하고 고친다 (음악도 같은 규칙으로 섞임).
   나레이션은 위스퍼로 다시 받아써서 원고와 다르게 들리는 단어(예: 훠궈→확고, 3천 원→3초는)가 있으면
   숫자는 한글로(이만 육천팔백 원), 어려운 외래어는 쉬운 말로 바꿔 다시 만든다.
4. 편 초안 폴더들을 `편/` 아래에 두고 `install_capcut.py` + `설치.bat` 과 함께 압축해 보낸다.
   압축은 파이썬 zipfile 로 만든다 (리눅스 zip 명령은 한글 이름 표시를 안 붙여 윈도우에서 깨진다).
   `설치.bat` 은 영어만, 줄바꿈은 CRLF 로 쓴다 (한글·LF 면 cmd 가 줄을 깨뜨려 실행이 안 된다).
   내용: `python "%~dp0install_capcut.py"` — 편 폴더(`편/`)와 원본 영상 폴더는 install_capcut.py 가 알아서 찾는다.

## 4. 사장님 PC에서
- 압축을 풀고 `설치.bat` → 원본 영상 폴더 주소 입력 → 캡컷 초안 폴더에 들어감.
- 캡컷이 켜져 있으면 꺼질 때까지 기다린다.
- 업체 프로젝트가 없으면 만들고, 있으면 `Timelines/project.json` 에 타임라인을 더한다 (03, 04…).
  같은 번호를 다시 넣으면 그 타임라인 내용만 바뀐다. 바꾸기 전 프로젝트는 `AppData\Local\CapCut 초안 백업` 에 복사.
- 캡컷 9.6 구조: `Timelines/project.json`(타임라인 목록), `Timelines/<ID>/draft_content.json`(타임라인 하나),
  맨 위 `draft_content.json`(메인 타임라인 사본).

## 알려진 한계
- 효과음은 넣지 않는다. 캡컷 음악 라이브러리는 쓸 수 없어서 배경음악은 일레븐랩스로 만든다.
- 타임라인 내용은 pycapcut(캡컷 6.7 형식)으로 만든다. 9.6 에서 처음 열 때 캡컷이 새 형식으로 바꾼다고 보고 있으며,
  사장님 PC에서 실제로 열어 확인해야 한다.
