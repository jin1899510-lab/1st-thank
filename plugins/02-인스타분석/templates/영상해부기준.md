# 영상 해부 기준 (화면·자막·전환·음성)

`extract_frames.py` 가 만든 `frames/<코드>/hook.jpg`(0~3초 0.5초 간격), `cuts.jpg`(장면마다 첫 화면),
`scenes.json`(전환 시점), 위스퍼 받아쓰기를 같이 보고 채운다. 결과는 `영상해부_결과.json`.

## 1 · 초반 3초
- **표지 글자**: 0초 화면에 큰 제목 글자가 있는지, 몇 초 보이는지
  - `순간 표지` = 0.1초 안팎만 보이고 넘어감 (피드·프로필 썸네일용)
  - `유지 제목` = 1초 이상 화면에 남음
  - 문구는 그대로 옮겨 적는다
- **첫 화면**: 결과(완성 음식·현장) / 이동(운전·입구) / 사람(얼굴·리액션) / 과정(주문·조리) / 분할 화면
- **0~3초 흐름**: 0.5초 간격 사진을 보고 장면이 어떻게 바뀌는지 한 줄로
- **첫 발화**: 위스퍼 첫 발화 초, 0~3초 동안 말한 초

## 2 · 글자(폰트)와 위치
- 폰트 이름은 사진만으로 알 수 없다. **모양**으로 적는다:
  굵기(얇음/보통/아주 굵음), 색(흰색/노랑/빨강…), 테두리·그림자·검은 띠, 효과(불꽃·손글씨·반짝이 스티커)
- **위치**: 화면 세로 기준 위(0~33%) / 가운데(33~66%) / 아래(66~100%), 가운데 정렬 여부
- 층을 나눠 적는다: `표지 제목` / `말 자막`(말을 그대로 옮긴 글) / `리액션 자막`(괄호 속 혼잣말 등) / `정보 글`(주소·기간)

## 3 · 전환
- `scenes.json` 의 장면 수, 장면당 평균 초, 3초 안 전환 수
- 전환이 **말하는 도중** 일어나는지, **말 쉬는 틈**에 일어나는지 (scenes.json 에 숫자 있음)
- 전환 방식: 그냥 자르기(하드컷) / 효과 전환(줌·밀기·번쩍) — cuts.jpg 로 보이는 만큼만

## 4 · 음성
- **형식**: 나레이션(나중에 입힌 설명) / 대화(현장 문답) / 리액션(현장 혼잣말·감탄) / 없음(음악만)
- **말 비율**: 영상 길이 중 말이 나오는 비율 (위스퍼 구간 합 ÷ 길이)

## 공통 규칙
- 사진에 보이는 것만 적는다. 안 보이면 `불명`.
- 움직임(줌·밀기 같은 효과 전환)은 정지 사진으로 확실히 알 수 없으면 `불명`으로 둔다.
- 상위와 하위를 같은 기준으로 보고, 차이가 숫자로 드러나는 것만 "차이"라고 쓴다.
