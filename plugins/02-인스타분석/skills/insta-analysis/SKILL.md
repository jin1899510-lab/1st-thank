# 인스타 분석

## 0. 화면으로 쓰기 (선택)
- `python3 scripts/web_app.py` → 브라우저에서 http://127.0.0.1:8765
- 계정이나 릴스 링크를 넣고 [수집하기]를 누르면 1~3단계를 차례로 돌리고, 릴스 표·초 단위 받아쓰기·비교표를 보여준다.
- 토큰은 환경변수나 `02-인스타분석/.env` 의 `APIFY_TOKEN=...` 에서 읽는다 (.env 는 저장소에 안 올라감).
- 4단계 해부는 화면의 [해부 요청 문구 복사]를 눌러 Claude에게 붙여넣는다.

## 1. 릴스 가져오기
- 사장님에게 분석할 인스타 계정 아이디 1개를 받는다. 릴스 링크를 받아도 된다 (올린 계정을 자동으로 찾음).
- 상위/하위 비교를 하려면 30개 이상 가져온다 (받아쓰기 포함).
- 실행: `python3 scripts/fetch_reels.py <계정아이디> 30 --transcript`
  - 공유 수까지 필요하면 `--shares` (Apify 유료 요금제만)
  - 음성 받아쓰기가 필요하면 `--transcript`
- 토큰은 환경변수 `APIFY_TOKEN` 에서 읽는다. 없으면 사장님에게 등록을 요청하고, 대화창에 붙여넣게 하지 않는다.
- 결과는 저장소 밖 `고객설정/인스타분석/<계정아이디>/<날짜>/` 에 저장된다.

## 2. 위스퍼 받아쓰기 (무료, 내 컴퓨터에서)
- Apify 받아쓰기는 시간이 없고 빠지는 말이 많다. 위스퍼로 다시 받아써서 **몇 초에 무슨 말을 했는지** 남긴다.
- 처음 한 번만 설치: `pip install -r requirements.txt` (faster-whisper. OpenAI API 키·비용 없음, ffmpeg 불필요)
- 실행: `python3 scripts/transcribe_whisper.py <결과폴더> --prompt "자주 틀리는 고유명사"`
  - 기본은 조회수 상위 10 + 하위 10개만 받아쓴다. 전부는 `--all`.
  - 모델 기본 `small` (CPU에서 릴스 1개에 10초 안팎). 더 정확하게는 `--model medium`.
  - 처음 실행 때 모델을 내려받는다 (small 약 0.5GB). 중간에 끊겨도 다시 돌리면 이어서 한다.
  - 인스타 영상 링크는 며칠 뒤 만료된다. 수집한 날 바로 돌리고, 만료됐다고 나오면 1단계를 다시 실행한다.
- 결과: `transcripts_whisper.json`, 음성 사본은 `audio/` (둘 다 저장소 밖 결과폴더).

## 3. 해부 자료 만들기
- 실행: `python3 scripts/prepare_dissect.py <결과폴더> 10`
- 조회수 상위 10개 / 하위 10개가 `해부_입력.md` 에 정리된다.
- 위스퍼 결과가 있으면 받아쓰기가 `[0.0~3.9초 | 0%]` 처럼 초·% 와 함께, 첫 발화 시점과 함께 들어간다.

## 4. 해부하기
- `templates/해부기준.md` 의 4개 레이어대로 상위·하위 릴스를 모두 해부한다.
- 모든 항목에 근거 원문 인용. 근거가 없으면 `불명`, 값은 null. 추측 금지.
- 영상을 봐야 아는 항목은 `[눈으로 확인]` 으로 모은다.
- 첫 발화 3초·보류 장치 초/%는 위스퍼 시간으로 채운다 (해부기준.md 참고).
- 결과를 같은 폴더의 `해부_결과.json` 으로 저장한다 (형식은 해부기준.md 맨 아래).

## 5. 비교와 정리
- 실행: `python3 scripts/compare_groups.py <결과폴더> 10` → `상위하위_비교.md`
- 사장님에게 보여줄 것 (쉬운 말, 숫자는 표로):
  1. 상위 10개 릴스별 해부표 (근거 인용 포함)
  2. [눈으로 확인] 목록
  3. 공통 패턴 3개
  4. 상위/하위 비교표와 눈에 띄는 차이 한 줄 해설
