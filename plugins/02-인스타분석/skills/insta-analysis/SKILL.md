# 인스타 분석

## 1. 릴스 가져오기
- 사장님에게 분석할 인스타 계정 아이디 1개와 가져올 개수(기본 10)를 받는다.
- 실행: `python3 scripts/fetch_reels.py <계정아이디> <개수>`
  - 공유 수까지 필요하면 `--shares` (Apify 유료 요금제만)
  - 음성 받아쓰기가 필요하면 `--transcript`
- 토큰은 환경변수 `APIFY_TOKEN` 에서 읽는다. 없으면 사장님에게 등록을 요청하고, 대화창에 붙여넣게 하지 않는다.
- 결과는 저장소 밖 `고객설정/인스타분석/<계정아이디>/<날짜>/` 에 저장된다.

## 2. 결과 보여주기
- `reels.csv` 를 읽어 조회수 높은 순 표로 보여준다 (숫자는 표로, 쉬운 말로).
