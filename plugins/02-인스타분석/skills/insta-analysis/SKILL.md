# 인스타 분석

## 1. 릴스 가져오기
- 사장님에게 분석할 인스타 계정 아이디 1개를 받는다. 릴스 링크를 받아도 된다 (올린 계정을 자동으로 찾음).
- 상위/하위 비교를 하려면 30개 이상 가져온다 (받아쓰기 포함).
- 실행: `python3 scripts/fetch_reels.py <계정아이디> 30 --transcript`
  - 공유 수까지 필요하면 `--shares` (Apify 유료 요금제만)
  - 음성 받아쓰기가 필요하면 `--transcript`
- 토큰은 환경변수 `APIFY_TOKEN` 에서 읽는다. 없으면 사장님에게 등록을 요청하고, 대화창에 붙여넣게 하지 않는다.
- 결과는 저장소 밖 `고객설정/인스타분석/<계정아이디>/<날짜>/` 에 저장된다.

## 2. 해부 자료 만들기
- 실행: `python3 scripts/prepare_dissect.py <결과폴더> 10`
- 조회수 상위 10개 / 하위 10개가 `해부_입력.md` 에 정리된다.

## 3. 해부하기
- `templates/해부기준.md` 의 4개 레이어대로 상위·하위 릴스를 모두 해부한다.
- 모든 항목에 근거 원문 인용. 근거가 없으면 `불명`, 값은 null. 추측 금지.
- 영상을 봐야 아는 항목은 `[눈으로 확인]` 으로 모은다.
- 결과를 같은 폴더의 `해부_결과.json` 으로 저장한다 (형식은 해부기준.md 맨 아래).

## 4. 비교와 정리
- 실행: `python3 scripts/compare_groups.py <결과폴더> 10` → `상위하위_비교.md`
- 사장님에게 보여줄 것 (쉬운 말, 숫자는 표로):
  1. 상위 10개 릴스별 해부표 (근거 인용 포함)
  2. [눈으로 확인] 목록
  3. 공통 패턴 3개
  4. 상위/하위 비교표와 눈에 띄는 차이 한 줄 해설

(카드 화면·원고 변환 단계는 다음 작업에서 추가)
