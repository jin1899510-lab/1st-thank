# 제안서 만들기

인자: 업체명 (없으면 업체명, 주소, 업종, 제공내역을 묻는다)

## 순서

1. **접수**: `intake` 에이전트 실행.
   - `누락항목`이 분석에 꼭 필요한 것(대표 키워드, 정확한 주소)이면 `request.md`를 사용자에게 보여주고 멈춘다.
   - 나머지만 비어 있으면 사용자에게 알리고 계속한다.
2. **분석 1단계**: `market-area`, `industry`, `place-rank`를 한 번에 동시 실행.
3. **분석 2단계**: `competitor`, `top-performer`를 한 번에 동시 실행.
4. **상품 매칭**: `product-matcher` 실행.
5. **레퍼런스**: `reference-collector` 실행.
6. **원고 작성**: `proposal-writer` 실행.
7. **검토**: 문제점, 매칭상품, 출처 없는 수치를 요약해 사용자에게 보여주고 확인을 받는다. 확인 후 카드 `상태`를 `검토완료`로 바꾼다.

각 단계가 끝나면 카드 `상태`를 갱신하고, 실패한 단계는 이유와 함께 보고한 뒤 나머지를 진행한다.
