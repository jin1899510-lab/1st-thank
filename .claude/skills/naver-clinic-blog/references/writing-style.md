# 네이버 원고 형식과 문체

## 문체
- 합니다체. 문장 끝은 "~합니다 / ~입니다 / ~습니다". "~해요, ~거예요"는 쓰지 않는다 (사용자가 "요요 거린다"고 지적한 이력 있음).
- 목록 항목은 명사형으로 끝내 "~습니다" 반복을 줄인다: "~하기", "~할 때", "~가능성", "~금지".
- 이모티콘(:), 😅), 이모지 소제목, "오늘의 한 줄" 같은 장치는 쓰지 않는다.
- 짧은 문장, 문단은 2~4줄. 모바일에서 읽기 좋게 줄바꿈.
- 어려운 개념은 생활 비유 하나로 푼다 (예: 리프팅 층 차이 = 집의 뼈대 vs 마감).

## 파일 형식 (빌더가 이 표기를 해석한다)

```
[제목 후보 - 하나 골라 제목칸에 입력]
1) 대표 제목 (지역 키워드 포함, 예: "천안피부과 | ...")
2) ...
3) ...


━━━━━━━━━━━━━━━━━━━━━━

[이미지 삽입 위치 - 대표 썸네일 (주제)]

안녕하세요.
<병원명>입니다.

[이미지 삽입 위치 - <캡션>]

도입 문단 (진료실에서 자주 듣는 질문/장면)


━━━━━━━━━━━━━━━━━━━━━━
■ 소제목
━━━━━━━━━━━━━━━━━━━━━━

본문 문단

· 점 목록 (이어지는 줄은 공백 한 칸으로 시작)
☐ 체크리스트 항목
→ 화살표 설명 (앞 줄에 붙어 강조 표시됨)
① / 1. / STEP 1. 번호 항목 (" – " 뒤는 설명 문단으로 분리)
Q1. 질문 항목
[확인 필요 : 병원 확인이 필요한 내용]


━━━━━━━━━━━━━━━━━━━━━━

맺음 문단 2~3줄
<병원명>였습니다.


━━━━━━━━━━━━━━━━━━━━━━
<병원 정식 상호>
━━━━━━━━━━━━━━━━━━━━━━

주소 : ...
전화 : ...
진료 : 평일 ...
　　　토요일 ... / 일요일 휴진
※ 진료 일정은 변동될 수 있으니 내원 전 전화로 확인 바랍니다.

[지도 삽입 - 네이버 지도에서 '<검색어>' 검색 후 삽입]

고지문 (일반 정보 목적, 개인차, 부작용, 전문의 상담)


[태그 - 태그칸에 입력]
#지역+진료과 #동네+진료과 #병원명 #주제키워드 ...
```

규칙:
- 소제목은 반드시 `━` 줄 / `■ 제목` / `━` 줄 3줄 세트.
- `━` 3줄 세트 안의 글이 `■`로 시작하지 않으면 병원 정보 박스로 인식된다 (원고 끝에 한 번만).
- `[이미지 ...]`, `[지도 ...]`, `[확인 필요 ...]`는 "본문 전체 복사"에서 자동으로 빠지거나 `[사진 N 넣는 곳]`으로 바뀐다.

## 글 구조 (권장 순서)
1. 썸네일 → 인사 → 도입 사진 → 공감 도입 (질문·장면)
2. 원리 설명 (왜 그런가)
3. 셀프 체크 또는 구별법
4. 집에서 할 수 있는 해결법 (번호 목록)
5. 이럴 땐 진료 (점 목록)
6. 맺음 → 병원 정보 → 지도 → 고지문 → 태그
