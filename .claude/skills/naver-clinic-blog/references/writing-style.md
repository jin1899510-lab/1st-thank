# 네이버 원고 형식과 문체

## 문체
- 합니다체. 문장 끝은 "~합니다 / ~입니다 / ~습니다 / ~바랍니다". "~해요, ~거예요"는 쓰지 않는다 (사용자가 "요요 거린다"고 지적한 이력 있음). 질문형 소제목·Q&A 질문도 "~합니까?", "~됩니까?"로 쓴다.
- 목록 항목은 명사형으로 끝내 "~습니다" 반복을 줄인다: "~하기", "~할 때", "~가능성", "~금지".
- 이모티콘(:), 😅), 이모지 소제목, "오늘의 한 줄" 같은 장치는 쓰지 않는다.
- 짧은 문장, 문단은 2~4줄. 모바일에서 읽기 좋게 줄바꿈.
- 어려운 개념은 생활 비유 하나로 푼다 (예: 피부 장벽 = 벽돌과 시멘트, 깊은 여드름 = 땅속 뿌리, 저온화상 = 약불에 오래 끓인 국).

## 문장 연결 (반드시 지킨다)
문장이 따로 노는 나열체가 되지 않게, 문단 안의 문장은 앞 문장과의 관계가 드러나는 연결어로 잇는다.

| 관계 | 연결어 |
|---|---|
| 이유·결과 | 그래서, 그러다 보니, 이 때문에, 그 결과 |
| 반대·전환 | 하지만, 다만, 그런데, 반면 |
| 덧붙임 | 또, 여기에, 게다가, 아울러 |
| 강조·구체화 | 특히, 실제로, 예를 들어, 즉 |
| 시간·상황 | 이때, 그러면, 이후, 그사이 |
| 정리 | 이처럼, 결국, 따라서, 정리하면 |

규칙:
- 문단의 두 번째 문장부터는 대부분 연결어나 지시어("이런 경우", "이 상태에서", "그 자리에")로 시작해 흐름을 잇는다. 단, 모든 문장에 기계적으로 붙이지는 않는다 (3~4문장 중 2~3문장 정도).
- 같은 연결어를 한 문단 안에서 반복하지 않고, 바로 앞 문단 첫머리와도 겹치지 않게 한다.
- 소제목이 바뀌는 첫 문장은 앞 섹션을 받아 넘긴다 ("그렇다면 내 여드름은 어느 쪽인지 살펴보겠습니다." / "원인을 알았으니 이제 집에서 할 수 있는 방법입니다.").
- 목록(·, ☐, 번호) 항목 자체에는 연결어를 붙이지 않는다. 대신 목록 앞 안내 문장과 목록 뒤 정리 문장으로 흐름을 잇는다.
- 연결어로 논리를 과장하지 않는다 ("그래서 확실히 낫습니다" 같은 효과 단정 금지).

예시:
- 나열체(피함): "공기가 건조해집니다. 지질이 빠져나갑니다. 가려움을 느낍니다."
- 연결된 글: "공기가 건조해지면 이 시멘트가 쉽게 빠져나갑니다. 그러다 보니 틈으로 수분이 날아가고, 작은 자극에도 가려움을 느끼게 됩니다. 특히 정강이와 팔 바깥쪽은 피지가 적어 가장 먼저 건조해집니다."

## 파일 형식 (빌더가 이 표기를 해석한다)

```
[제목 후보 - 하나 골라 제목칸에 입력]
1) 대표 제목 (지역 키워드 포함, 예: "양재피부과 | ...")
2) ...
3) ... (시술명보다 증상·정보 중심)


━━━━━━━━━━━━━━━━━━━━━━

[이미지 삽입 위치 - 대표 썸네일 (주제)]

안녕하세요.
<지점 강점 문구> <병원 정식 상호>입니다.

[이미지 삽입 위치 - <캡션>]

도입 문단 (진료실에서 자주 듣는 질문/장면)


━━━━━━━━━━━━━━━━━━━━━━
■ 소제목
━━━━━━━━━━━━━━━━━━━━━━

본문 문단

· 점 목록 (이어지는 줄은 공백 한 칸으로 시작)
☐ 체크리스트 항목
→ 화살표 설명 (앞 줄에 붙어 강조 표시됨)
① / 1. / STEP 1. 번호 항목 (" – " 뒤는 설명 문단으로 분리)
Q1. 질문 항목 (다음 줄부터 답변 문단)

━━━━━━━━━━━━━━━━━━━━━━
<병원 정식 상호>
━━━━━━━━━━━━━━━━━━━━━━

(정보 박스: 01_지점_작성지침.md의 블록 그대로)

[지도 삽입 - 네이버 지도에서 '<검색어>' 검색 후 삽입]

본 글은 일반적인 <진료과> 건강 정보 제공을 목적으로 합니다.
(주제에 맞는 개인차·부작용 문장)

본문 이미지는 이해를 돕기 위한 연출 이미지로, 실제 환자나 의료진의 사진이 아닙니다.

의료광고 심의필 번호 : 심의 승인 후 기재
[확인 필요 : 의료광고 사전심의 승인 후 심의필 번호 기재, 승인받은 내용과 동일하게 게시]


[태그 - 태그칸에 입력]
#지역+진료과 #역+진료과 #병원브랜드 #진료과전문의 #지역진료과전문의 #주제키워드 ... (10개 내외)
```

규칙:
- 소제목은 반드시 `━` 줄 / `■ 제목` / `━` 줄 3줄 세트.
- `━` 3줄 세트 안의 글이 `■`로 시작하지 않으면 병원 정보 박스로 인식된다 (원고 끝에 한 번만).
- `[이미지 ...]`, `[지도 ...]`, `[확인 필요 ...]`는 "본문 전체 복사"에서 자동으로 빠지거나 `[사진 N 넣는 곳]`으로 바뀐다. 그래서 꼭 남아야 하는 줄(심의필 번호)은 `[확인 필요]`와 별도의 일반 줄로 쓴다.

## 글 구조 (권장 순서)
1. 썸네일 → 인사(강점 문구) → 도입 사진 → 공감 도입 (질문·장면)
2. 원리 설명 (왜 그런가, 생활 비유)
3. 셀프 체크 또는 구별법 → "정확한 구별은 전문의 진찰로 확인" 문장
4. 이것만은 하지 마십시오 (흔한 실수와 그 이유)
5. 집에서 할 수 있는 해결법 (번호 목록)
6. 병원에서는 어떻게 하는가 (강점 문장 + 방법 + 부작용 + 개인차)
7. 자주 받는 질문 Q1~Q3
8. 진료가 필요한 때 (점 목록)
9. 맺음 → 병원 정보 → 지도 → 고지문 → 심의필 번호 → 태그
