# <병원 정식 상호> 작성 지침

출처: 네이버 플레이스 (<날짜>, 사용자 제공), 건강보험심사평가원 진료과목별 전문의 정보, <기타>

## 강조할 강점 (확인된 사실만)
- 예: <진료과> 전문의 <N>명 (심평원 기준), <원장 이름> <진료과>전문의
- 원고마다 아래 자리에 자연스럽게 넣는다.
  1. 첫 인사: "<진료과> 전문의가 진료하는 <상호>입니다."
  2. 진료 섹션 첫 문장: "<상호>은(는) <진료과> 전문의 <N>인이 진료합니다." 판단 주체를 "<진료과> 전문의"로 적는다.
  3. 셀프 체크·구별법 뒤: "정확한 구별은 <진료과> 전문의의 진찰로 확인하시기 바랍니다."
  4. 병원 정보 박스: `의료진 : <진료과> 전문의 <N>인`
  5. 태그: #<진료과>전문의 #<지역><진료과>전문의
- 확인되지 않은 의료진 이름·경력·학회 직함은 쓰지 않는다. 인원은 게시 시점에 다시 확인한다.

## 심의 안에서 강조하는 법
- 쓸 수 있음: "<진료과> 전문의 N인 진료", "전문의가 직접 진찰" (사실)
- 쓰지 않음: 다른 의료인과 비교("일반의와 달리"), 최상급("최고 전문의", "권위자"), 전문의라서 효과가 확실하다는 연결

## 정보 박스 (원고 끝, 모든 원고 동일)
```
<정식 상호>
주소 : <주소> (<노선> <역> <N>번 출구에서 약 <N>m)
전화 : <플레이스 표시 번호>
의료진 : <진료과> 전문의 <N>인
진료 : <요일> <시간>
　　　<요일> <시간>
　　　토요일 <시간> / 일요일 <휴무>
　　　평일 점심시간 <시간>
주차 : <주차 정보, '무료' 표기 없이>
※ 진료 일정은 변동될 수 있으니 내원 전 전화로 확인 바랍니다.

[지도 삽입 - 네이버 지도에서 '<검색어>' 검색 후 삽입]
```

## 이미지
- 모든 이미지(썸네일 포함) 4:5 세로 실사. 원리 설명은 생활 속 비유 사물 실사.
- 상담 장면은 얼굴이 나오지 않는 손·책상 위주, 의료 장비 없음. 가능하면 병원 실제 사진으로 교체.
