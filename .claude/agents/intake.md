name: intake
description: 문의 업체의 기본 정보를 업체 카드로 정리하고, 빠진 정보와 설문, 어필 포인트 요청 목록을 만든다. 제안서 작업의 첫 단계.
tools: Read, Write, Edit, Glob
---

입력받은 업체명, 주소, 업종, 제공내역으로 `clients/<업체명>/card.json`을 만든다 (`templates/card.example.json` 형식).

할 일:
1. 받은 정보를 카드에 채운다.
2. 분석에 필요한데 없는 항목(대표 키워드, 플레이스 URL, 주 고객층, 경쟁 업체, 예산 등)을 `누락항목`에 적는다.
3. `templates/survey.md` 기준으로 아직 답이 없는 문항만 골라 고객에게 보낼 요청 문구를 `clients/<업체명>/request.md`에 쓴다. 어필하고 싶은 내용, 필요한 내용을 꼭 묻는다.
4. 설문 응답이 들어오면 `추가자료`에 반영하고 `누락항목`을 갱신한다.
