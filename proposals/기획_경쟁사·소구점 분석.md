# 기획: 경쟁사·소구점 분석 → 우리 업체 소구점 만들기 → 표현법

작성 2026-11-21 · 상태: 기획안 (대표님 확인 후 제작)

## 0. 목적 한 줄
"주변 경쟁사와 전국의 잘되는 같은 업종이 **무엇을, 어떻게** 손님에게 어필하는지"를 리뷰·메뉴·가격·소개글로 세세하게 뜯어 보고, 우리 업체의 진짜 강점과 맞춰 **우리만의 소구점과 그 표현 문장**까지 만들어 준다.

## 1. 전체 흐름 (6단계)

```
① 우리 업체 조사 ─┐
② 반경 경쟁사 조사 ├─▶ ③-1 상권 유형 붙이기 ─▶ ④ 소구점 지도 ─▶ ④-1 접목 추천(상권 맞춤) ─▶ ⑤ 우리 소구점 설계 ─▶ ⑥ 표현법·적용처
③ 전국 같은 업종 ─┘
```

| 단계 | 하는 일 | 누가 | 결과 파일 |
|---|---|---|---|
| ① 우리 업체 | 플레이스(소개·메뉴·가격·사진·쿠폰·소식), 리뷰 키워드·리뷰 본문, 히든 키워드·순위, 업체 폴더 자료(정보뱅크·차별화 파일·사장님 질문지) | 도구 수집 + Claude 정리 | `data/appeal/our.json` |
| ② 반경 경쟁사 | 메인 키워드 5개 × 상위 10곳 + 반경 안 같은 업종·비슷한 업종 → 경쟁사 목록 | 도구 | `data/appeal/competitors.json` |
| ③ 전국 같은 업종 | 대표 메뉴 키워드로 주요 도시 상위 매장 + 유명 브랜드·방송·블루리본 | 도구 + 검색 | `data/appeal/national.json` |
| ③-1 상권 유형 | 우리·경쟁사·전국 사례 매장마다 주변 시설과 리뷰의 방문 상황으로 상권 유형을 붙임 (학원가·주거·오피스·역세권·관광·랜드마크·대학가) | 도구 + Claude | 각 매장 `area_tags` |
| ④ 소구점 지도 | 경쟁사마다 "무엇을(소구점) · 어떻게(표현) · 근거(리뷰 수)" 카드 | Claude 분석 | `appeal_report.md` 1–3장 |
| ④-1 접목 추천 | 경쟁사·전국 사례의 방법 중 **우리 상권·우리 손님 상황에 맞는 것만** 골라 우리 식으로 바꿈, 맞지 않는 건 이유와 함께 뺌 | Claude | `appeal_report.md` 5장 |
| ⑤ 우리 소구점 | 강점 후보 → 점수 → 소구점 3–5개 확정, 경쟁사 소구점을 우리 것으로 바꾸는 방법 | Claude + 대표님 확인 | `appeal_report.md` 4–5장 |
| ⑥ 표현법 | 소구점별 문장(한 줄·설명·후기형), 어디에 쓰는지(플레이스 소개·대표키워드·메뉴명·사진·소식·광고 문구·콘텐츠) | Claude | `appeal_report.md` 6장 + E드라이브 차별화 파일 |

## 2. 수집 상세

### ① 우리 업체
- 플레이스: 소개글, 대표키워드, 메뉴 전체(이름·설명·가격·사진 유무·세트 여부), 편의시설, 쿠폰·소식, 사진 수, 예약·주문 여부
- 리뷰: 방문자·블로그 리뷰 수, 최근 30·90일 리뷰 속도, '이런 점이 좋았어요' 전체, 메뉴 언급 수, 특징(맛·양·가격·서비스·분위기) 언급 수, **리뷰 본문 최근 100개**
- 애드로그: 키워드 순위, 히든 키워드
- 업체 폴더(E드라이브): 정보뱅크, 차별화·소구점 파일, 사장님 질문지 답변, 언론·방송 기록 — 있으면 가장 먼저 읽는다

### ② 반경 경쟁사 (대표님 기준 그대로)
1. **메인 키워드 5개 정하기**: 우리 대표키워드·히든 키워드·리뷰 메뉴 언급에서 후보를 뽑고, 네이버 검색광고 API 월간 검색수로 많이 찾는 순 5개 (예: 장산역 맛집, 장산역 초밥, 해운대 초밥, 장산역 연어덮밥, 장산역 일식)
2. **키워드별 상위 10곳** (매장 좌표 기준 네이버 플레이스) → 겹치는 곳 합치기
3. **반경 안 같은 업종·비슷한 업종**: 업종명(예: 일식당, 초밥·롤, 돈가스)으로 반경 검색 → 위 목록에 없는 곳 추가
   - 같은 업종 = 카테고리가 같은 곳 / 비슷한 업종 = 같은 손님·같은 상황(점심·혼밥·가족 외식)을 두고 다투는 곳
4. 경쟁사마다 모으는 것 (우리와 같은 항목):
   - 리뷰 수(방문자·블로그), 최근 리뷰 속도, 리뷰 키워드 상위, 메뉴 언급·특징 언급
   - **리뷰 본문 30–50개** → 손님이 실제로 칭찬하는 말 / 아쉬워하는 말
   - **메뉴·가격**: 대표 메뉴와 가격, 1인 기준 예상 객단가, 세트·코스, **상차림(기본 반찬·국·샐러드)**, **사이드(추가 메뉴·무한리필·서비스)** — 메뉴판 설명 + 리뷰 본문 + 사진 설명에서 찾는다
   - 소개글·대표키워드·메뉴 이름 짓는 방식, 사진 첫 장 구성
   - 쿠폰·이벤트·소식, 키워드 순위·히든 키워드 수, 파워링크·플레이스 광고 문구

### ③ 전국 같은 업종
- 대표 메뉴 키워드(예: 연어덮밥, 족발, 국밥)로 **주요 도시 5곳(서울 강남·홍대, 부산 서면, 대구 동성로, 대전 둔산)** 상위 5곳씩 → 리뷰가 가장 많은 곳·빠르게 늘어나는 곳 우선
- 유명 브랜드·프랜차이즈, 블루리본·방송 출연 매장(검색으로)
- 모으는 것: 소개글·메뉴 구성·가격대·상차림·사이드, 리뷰 키워드 상위, 손님이 감탄하는 포인트, 이름 짓기·사진·이벤트 방식
- 목적: "우리 동네엔 없지만 전국에선 통하는 방식" 찾기

## 2-1. 업종별 상권 범위 — 손님이 어디서 오느냐에 따라 경쟁사 찾는 법이 다르다 (2026-11-21 추가)

| 유형 | 업종 예 | 손님이 오는 범위 | 경쟁사 찾는 법 | 경쟁사 수 |
|---|---|---|---|---|
| ① 동네형 | 외식, 카페, 병원·의원, 학원, 미용실(일반) | 매장 반경 0.5–2km | 메인 키워드 5개 상위 10곳 + 반경 안 같은·비슷한 업종 (지금 방식) | 15–30곳 |
| ② 시·구 권역형 (출장·방문) | 청소(입주·이사·사무실), 이사, 하수구·배관, 인테리어·집수리, 방역, 에어컨 청소 | 서비스 가능 지역 (시·구 단위) — 매장 위치보다 **출장 범위**가 중요 | '지역 + 업종' 키워드를 시·구마다 (예: 부산 입주청소, 해운대 입주청소, 수영구 하수구) 10–15개 × 플레이스 상위 10 + 파워링크 광고주 + 파워컨텐츠·블로그 상위 + 숨고·당근 업체 | 30–50곳 |
| ③ 전국형 | 법률, 세무·회계, 온라인 판매(쇼핑몰·스마트스토어), 프랜차이즈 가맹 모집, 교육·컨설팅 | 전국 (지역 무관, 온라인 상담) | 지역 없는 키워드 15–20개 (예: 상속 변호사, 종합소득세 신고 대행, 치킨 창업) × 파워링크·파워컨텐츠 광고주, 구글·네이버 상위 사이트, AI 검색 추천, 유튜브 채널, 스마트스토어·쿠팡 상위(판매업) | 30–60곳 |
| ④ 목적지형 (찾아오는 업종) | 출산·산후 마사지, 붙임머리, 네일, 속눈썹, 타투, 반영구, 웨딩·스튜디오, 반려동물 미용, 퍼스널컬러 | 시 전체·옆 도시까지 (멀어도 찾아옴) | 시 단위 키워드 + 손님이 모이는 중심지 (예: 부산 서면·해운대·센텀·남포, 서울 강남·홍대·성수) × 플레이스 상위 + **인스타 해시태그 상위 계정** + 네이버 예약 상위 | 30–50곳 |

### 유형마다 더 보는 것
- **② 권역형**: 출장 가능 지역·출장비, 가격표 공개 여부(평당·건당·기본+추가), 견적 방식(사진 견적·현장 방문·카톡), 보증·AS 기간, 작업 전후 사진, 장비, 당일·야간·주말 가능, 숨고·당근 후기 수, 블로그 시공 후기 개수, 파워링크 문구의 혜택(무료 견적·당일 출동)
- **③ 전국형**: 파워링크·파워컨텐츠 문구와 키워드, 홈페이지 첫 화면 메시지·상담 유도 방식(전화·카톡·무료 상담·자료 받기), 전문 분야 나누기(분야별 사이트), 후기·사례 공개 방식, 가격 공개 여부, 유튜브·칼럼·언론, AI 검색 추천 여부. 판매업은 상세페이지 첫 화면·리뷰 수·가격·배송·혜택, 프랜차이즈는 창업 비용·수익 사례·지원 내용
- **④ 목적지형**: 포트폴리오 사진(스타일·전후), 인스타 팔로워·게시물 수·릴스 조회, 가격표, 첫 방문 혜택, 네이버 예약·리뷰 사진 비율, 재방문 주기(리필·리터치), 원장 경력·자격, 위생·1인샵 여부
  - **손님이 실제로 얼마나 멀리서 오는지**를 리뷰 본문의 지역 이름("○○에서 왔어요", "멀리서", "차 타고")과 동행·목적으로 센다 → 우리 상권 범위를 숫자로 정함
  - 같은 도시 중심지 경쟁사를 먼저, 그다음 전국의 유명 계정(스타일·가격 기준점)

### 정하는 방법
- 업종(플레이스 카테고리)으로 유형을 자동 추천하고, 대표님이 바꿀 수 있게 한다 (`--scope local|city|national|destination`)
- 한 업체가 두 유형일 수 있다 (예: 출장도 하고 매장도 있는 하수구 업체 = ② + ①) → 둘 다 조사
- 반경이 큰 유형(②③④)은 경쟁사를 많이 본다 (30–60곳). 리뷰 본문은 경쟁사마다 30개로 줄이고 대신 매장 수를 늘린다

## 2-2. 업종별 분석 포인트 — 업종마다 손님이 고르는 기준이 다르다 (2026-11-21 추가)

| 업종 묶음 | 손님이 고르는 기준 (먼저 볼 것) | 경쟁사에서 뜯어볼 것 |
|---|---|---|
| 외식 | 맛·메뉴, 양·가성비, 상차림·사이드, 분위기, 상황(혼밥·가족·데이트) | 메뉴명·가격·구성, 리뷰 칭찬, 사진 첫 장, 쿠폰·이벤트 |
| **전문직 (법률·세무·노무·회계)** | **전문성**, 내 사건과 같은 경험, 비용·과정의 투명함, 상담 쉬움, 신뢰 | 전문성 표현 방식(아래 표), 분야 나누기, 상담 유도, 사례·칼럼, 비용 안내 |
| **병원·의원** | **전문성(전문의·경력)**, 진료 과정·장비 설명, 통증·회복·부작용 걱정 풀어 주기, 친절·대기 | 전문성 표현 방식, 진료 과정 공개, 원장 소개, 정보성 콘텐츠, 의료광고 규정 지키는 문장 |
| 미용·목적지형 (네일·붙임머리·타투·산후 마사지) | 결과물 사진(스타일), 원장 실력·경력, 위생, 가격, 예약 쉬움 | 포트폴리오, 인스타, 가격표, 첫 방문 혜택, 리터치 정책 |
| 출장·방문 (청소·이사·하수구) | 믿을 수 있나, 가격 투명, 빠른 출동, 보증·AS, 전후 사진 | 견적 방식, 가격표, 보증, 작업 사진, 후기 |
| 온라인 판매 | 상품 차이, 리뷰 수·사진 리뷰, 가격·혜택, 배송 | 상세페이지 첫 화면, 리뷰, 혜택, 묶음 구성 |
| 프랜차이즈 가맹 | 수익·비용, 본사 지원, 실패 위험 줄이기, 점주 이야기 | 창업 비용 공개, 수익 사례, 지원 항목, 광고 문구 |

### 전문 업종: 전문성을 "어떻게 표현하는지" 뜯어보기
경쟁사(같은 지역 + 전국 상위)의 홈페이지 첫 화면·의료진/구성원 소개·플레이스 소개·광고 문구·칼럼을 원문으로 모아, 아래 **표현 기법**별로 분류한다.

| 표현 기법 | 무엇을 보여 주나 | 예 (형식) | 규정 주의 |
|---|---|---|---|
| 자격 증명형 | 자격·전문의·인증 | "피부과 전문의", "세무사·회계사 함께" | 변협 '전문'은 등록 시만, 병원 '전문의'는 사실일 때만 |
| 경험 수치형 | 경력 연수·처리 건수 | "상속 사건 ○○건", "개원 ○년" | 수치는 근거 있어야, 승소율·'최고' 금지 |
| 사례 해설형 | 비슷한 사건·증상을 풀어 설명 | "이런 경우 이렇게 진행됩니다" | 의료는 치료 전후 사진·후기 규정, 법률은 결과 단정 금지 |
| 과정 공개형 | 상담→진행→결과 단계, 비용 기준 | "상담 30분 → 서류 → 진행 일정" | 비용 '최저·무료' 표현 주의 |
| 대표자 이야기형 | 왜 이 일을 하는지, 얼굴·목소리 | 원장·대표 인터뷰, 영상 | '출신' 내세우기 주의(법률) |
| 제3자 권위형 | 언론·방송·강의·저서·학회 | "○○ 칼럼 연재", "학회 발표" | 확인된 것만 |
| 분야 세분화형 | 분야별 전용 페이지·사이트 | "상속 전담", "기업 노무" 페이지 | |
| 교육·정보형 | 칼럼·영상으로 먼저 도움 | 블로그 칼럼, 유튜브 해설, AI 검색 인용 | 정보와 광고 구분 |
| 접근성형 | 상담 쉬움·빠른 답 | 카톡 상담, 야간·주말, 지점 | |

- 경쟁사마다 어떤 기법을 쓰는지 ●/○ 표 → **다들 쓰는 기법 / 아무도 안 쓰는 기법** → 우리 업체가 실제로 가진 근거(자격·경력·사례·언론)로 쓸 수 있는 기법을 고른다
- 같은 기법이라도 "어떤 문장으로 쓰는지" 잘 쓴 예 3개, 규정에 걸리는 예(하지 말 것) 2개를 함께 모은다
- 병원은 의료광고 사전심의·금지 표현, 법률은 변협 광고 규정, 세무는 세무사 광고 규정을 보고서에 표시한다

## 3-1. 상권 맞춤 접목 추천 — "그 가게에서 통한 방법이 우리 상권에서도 통할까?"

같은 방법도 상권이 다르면 결과가 다르다. 랜드마크 앞 매장의 '인증샷 메뉴'는 관광객 상권이라 통하고, 학원가 매장에선 '학원 끝나고 10분 안에 먹는 세트'가 통한다. 그래서 방법을 옮기기 전에 **그 방법이 어떤 손님 상황 때문에 통했는지**부터 본다.

### ① 매장마다 상권 유형 붙이기 (우리·경쟁사·전국 사례 모두)
- **주변 시설 (매장 기준 300m·500m, 네이버 플레이스 반경 검색)**: 학원·초중고, 아파트·오피스텔, 회사·오피스 빌딩, 지하철역 출구, 관광지·랜드마크·호텔, 대학교, 대형마트·병원
- **동 인구 (area)**: 1인 세대 비율, 세대당 인구, 많은 연령대, 직장인구(SGIS 확인)
- **리뷰의 방문 상황**: 네이버 리뷰의 동행(혼자·친구·가족·연인·아이와), 목적(데이트·모임·회식·여행), 본문 단어("학원 끝나고", "여행 와서", "회식", "점심시간")
- → 유형 태그 1–2개: 학원가 / 주거(가족) / 주거(1인) / 오피스 / 역세권 / 관광·랜드마크 / 대학가 / 병원가 / 시장·생활
  - 예) 네코노무라: 주변 학원 다수(50–290m)·초중학교·아파트 + 장산역 250m → "학원가 + 주거(가족) + 역세권" 🔶 확인 필요

### ② 방법마다 "왜 통했나"를 손님 상황으로 적기
| 방법 (출처 매장 · 상권 유형) | 통한 이유 = 손님 상황 (누가 · 언제 · 누구와 · 왜) | 근거 |
|---|---|---|
| 예) 인증샷용 대형 메뉴 (○○, 관광·랜드마크) | 여행객이 · 주말 낮에 · 친구·연인과 · 기념으로 | 리뷰 '여행' 언급, 사진 리뷰 비율 |
| 예) 오후 4–6시 학생 세트 (○○, 학원가) | 중고생이 · 학원 전후 · 혼자·친구와 · 빨리 싸게 | 리뷰 '학원' 언급, 방문 시간대 |

### ③ 우리 상권에 같은 손님 상황이 있는지 확인 → 적합도 점수
| 기준 (각 5점) | 보는 것 |
|---|---|
| 상권 일치 | 출처 매장과 우리 상권 유형이 같은가 (다르면 0–2점) |
| 손님 일치 | 그 손님(연령·가구 형태)이 우리 동에 많은가 — area 인구 표 |
| 시간대·상황 일치 | 그 시간·상황이 우리 주변에 있나 — 학원 하원 시간, 점심 직장인, 주말 가족 등 |
| 우리가 할 수 있나 | 메뉴·인력·공간·가격으로 실제로 가능한가 (사장님 확인) |
| 비용·속도 | 바로 할 수 있나 / 1–3개월 걸리나 |
- 20점 이상 = 추천, 13–19점 = 바꿔서 추천, 12점 이하 = 빼고 이유만 적음

### ④ 맞지 않으면 "버리지 말고 바꿔서" 적용
- 원래 방법의 핵심(손님이 좋아한 이유)만 남기고, 우리 상권 손님에 맞게 바꾼다
  - 예) 랜드마크 매장의 '인증샷 메뉴' → 학원가 우리 매장: 아이들이 사진 찍어 부모님께 보내는 '오늘 간식 인증' 소식 + 부모님 대상 '학원 끝나고 픽업 포장'
  - 예) 오피스 상권의 '점심 10분 세트' → 주거 상권 우리 매장: '평일 저녁 퇴근길 포장 세트'
- 상권이 같은 사례(주변 경쟁사)는 그대로 빌려도 되지만, 이미 다들 하면 '경쟁 많음'으로 표시하고 차별을 더한다

### ⑤ 보고서 표 — 접목 추천
| 추천 방법 | 어디서 배웠나 (매장 · 상권) | 왜 통했나 (손님 상황) | 우리 상권에 맞나 (근거: 인구·시설·리뷰) | 우리 식으로 바꾼 모습 | 적합도 | 언제 (바로 / 1–3개월) |

- 전국 사례는 상권 유형이 같은 곳을 먼저 고른다 (학원가 매장이면 다른 도시의 학원가 매장 — 예: 서울 대치동, 부산 해운대 좌동, 대구 범어동, 대전 둔산 학원가)
- 그래서 ③ 전국 조사 도시는 고정 5곳 + **우리와 같은 상권 유형의 대표 지역**을 추가한다

## 3. 분석 틀

### ④ 소구점 지도 — 경쟁사마다 한 장
| 항목 | 내용 |
|---|---|
| 가게가 말하는 것 | 소개글·메뉴명·사진·광고 문구가 내세우는 점 |
| 손님이 말하는 것 | 리뷰 키워드 수·본문에서 반복되는 칭찬 (근거 숫자) |
| 소구점 종류 | 맛·재료 / 양·가성비 / 가격 / 메뉴 구성(상차림·사이드) / 분위기·공간 / 서비스·친절 / 편의(주차·예약·포장·혼밥) / 스토리·전문성 / 권위(방송·수상·오래됨) |
| 어떻게 표현하나 | 실제 문장 예시 (소개글·리뷰에서 그대로, 출처 표시) |
| 약점·불만 | 리뷰의 아쉬운 점 (대기·가격·양·불친절 등) |

→ 한 표로 모으면 **"모두가 하는 소구점(경쟁 많음)"**과 **"아무도 안 하는데 손님이 원하는 것(빈자리)"**이 보인다.

### 메뉴·가격·상차림 비교표
| 매장 | 대표 메뉴 (가격) | 1인 객단가 | 세트·코스 | 상차림 | 사이드·서비스 | 손님 반응 (리뷰) |

### ⑤ 우리 소구점 설계
1. **강점 후보 모으기**: 우리 리뷰 칭찬(숫자), 메뉴·가격 차이, 사장님 이야기·경력, 위치·편의, 상권 타겟(area: 1인 가구·가족·연령)
2. **점수 매기기** (후보마다 5점씩):
   - 손님이 원하나 (리뷰·검색량) / 우리가 진짜 잘하나 (근거) / 경쟁사가 안 하나 (빈자리) / 말로 쉽게 전해지나 / 사진·콘텐츠로 보여 줄 수 있나
3. **경쟁사 소구점 → 우리 것으로 바꾸는 4가지 방법**
   - 빌리기: 다들 통하는 소구점을 우리 근거로 (예: '가성비' → 우리 1인 한상 가격·구성으로 증명)
   - 쪼개기: 넓은 소구점을 우리만의 장면으로 (예: '혼밥 좋아요' → '점심 혼밥 한상 12분')
   - 뒤집기: 경쟁사 약점을 우리 강점으로 (예: 경쟁 리뷰 '대기 길어요' → 우리 '예약·포장 바로')
   - 빈자리 차지: 손님은 원하는데 아무도 말 안 하는 것
4. **확정**: 핵심 소구점 1개(한 줄 정체성) + 보조 소구점 2–4개, 각각 근거·타겟 손님·쓸 곳

### ⑥ 표현법
- 소구점마다 문장 3종: ① 한 줄 카피(15자 안팎) ② 설명 문장(왜 좋은지 '왜'를 풀어 줌) ③ 손님 후기형(실제 리뷰 말투를 바탕으로)
- 외식업은 음식 표현 지침(소리·식감·눈코입·먹는 법·장면·비유·한 줄 맺음), 모든 업종 고급스럽고 친절한 말
- 쓰는 곳별 예시: 플레이스 소개글·대표키워드·메뉴 이름·메뉴 설명·사진 첫 장 순서·소식·쿠폰 문구·리뷰 답글·파워링크/파워컨텐츠 문구·인스타·블로그 첫 문장
- 금지: 사실 왜곡, 경쟁사 실명 비교, 최상급(병원은 의료광고 규정, 법률은 변협 규정)
