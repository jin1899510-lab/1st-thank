# 감사한 마케팅 성과 사례

제안서 '성공 사례' 장에서 가장 강한 근거다. **실제 수치와 확인 방법이 있는 것만** 적는다. 고객 이름은 공개 동의를 받은 경우에만 제안서에 쓰고, 아니면 "해운대 족발 포장점"처럼 업종·지역으로만 쓴다.

## 적는 방법
| 항목 | 예시 |
|---|---|
| 업체 (공개 이름) | 해운대 족발 포장점 (이름 공개 X) |
| 업종·형태·지역 | 족발 · 포장/배달 · 부산 해운대 |
| 관리 기간·상품 | 2026-11 ~ 2027-01, 매월 관리 |
| 관리 전 | 방문자 리뷰 27, 블로그 리뷰 11, '장산역 족발' 10위 |
| 관리 후 | (관리 후 수치) |
| 한 일 | 쿠폰·소식 세팅, 체험단 10회/월, 인스타 기자단 2회/월 … |
| 확인 방법 | 애드로그 순위 기록, 플레이스 화면 캡처(날짜), 스마트플레이스 통계 |
| 공개 동의 | 예 / 아니오 |

## 사례
(아직 없음 — 대표님이 주시는 기존 고객 성과, 또는 계약한 고객의 월간 보고서 수치로 채운다.)
