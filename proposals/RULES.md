# 제안서 작성 규칙

대표님이 정한 규칙이다. 모든 제안서에 적용한다.

1. **가격은 맨 마지막 슬라이드에만** 넣는다. 표지·본문·다음 단계에는 금액을 쓰지 않는다.
2. **월 제공 서비스**는 노션 '외식업 광고 관리 상품 -수정중' 페이지에서 해당 상품의 항목과 수량을 그대로 가져와 별도 슬라이드로 보여 준다.
3. **설문지(고객 질문지) 내용은 넣지 않는다.** 구글폼 언급도 뺀다.
4. **추천은 사실에 근거한다.** 추천마다 출처(수집 데이터, 기사, 공식 자료)를 붙이고, 출처가 없는 의견은 넣지 않는다. 개인 주장이나 기업 발표는 그렇다고 밝힌다.
5. **성공 사례를 매번 조사해서 넣는다.** 같은 업종의 매장 사례(오프라인·포장·할인 등)와 온라인 마케팅 사례를 함께 넣고, 날짜와 출처를 표시한다. 자세한 방법은 아래 '성공 사례 분석 방법'을 따른다.

## 키워드별 검색 노출 조사 (모든 채널)
키워드 분석에서 나온 키워드(메인·세부·지역+업종·지역+제공내역)를 **하나씩 그대로 검색**해서 채널별로 세세하게 기록한다.

| 채널 | 확인 방법 | 기록할 것 |
|---|---|---|
| 네이버 플레이스 | 매장 좌표 기준 플레이스 목록, 애드로그 순위·히든 키워드 | 순위, 상위 10곳, 리뷰·사진·쿠폰·소식 |
| 네이버 통합검색 | 모바일 통합검색 결과 | 우리 매장·경쟁사 노출 여부, 블로그·카페 글 |
| 네이버 AI 브리핑 | 통합검색의 AI 브리핑 블록 | 브리핑이 뜨는지, 어떤 매장을 추천하는지 |
| 구글 지도 | `gsk maps-search` (구글 지도) | 매장 등록 여부, **상호·전화·영업시간이 네이버와 같은지**, 별점, 경쟁사 별점 |
| 구글·웹 검색 | `gsk search` | 상위 10개 결과(블로그·인스타·유튜브·다이닝코드 등)에 누가 나오는지 |
| AI 검색 | 젠스파크 등 AI 검색 답변 | 키워드로 물었을 때 추천에 우리 매장이 나오는지 |

- 키워드 × 채널 표로 정리하고, 우리 매장이 빠진 곳과 잘못 등록된 곳을 '바로 할 수 있는 방법'으로 연결한다.

## 성공 사례 분석 방법
업종에 맞춰 세세하게 분석하고, 사례마다 **바로 할 수 있는 방법**과 **적용할 수 있는 방법**을 함께 정리한다.

**1. 조사 범위 (업종별로 좁혀서)**
- 같은 업종·같은 운영 형태 우선 (예: 족발 포장 전문 → 족발·보쌈 포장/배달 매장 → 포장 중심 외식업 순)
- 같은 상권(반경 1–3km) 상위 매장의 현재 운영 방식: 플레이스 쿠폰·소식·편의시설(테이크아웃 할인 등)·메뉴 구성·사진·배달앱 메뉴명
- 같은 업종 프랜차이즈·개인 매장의 기사, 공식 발표, 사장님 공개 사례
- 온라인: 리뷰·플레이스, 숏폼(인스타·유튜브), 당근, 맘카페, 배달앱 운영 사례
- 업종 특성 반영 (예: 외식업은 시즌 메뉴·포장/배달, 병원은 의료광고 심의 규정 안에서 가능한 것만)

**2. 사례마다 정리할 항목**
| 항목 | 내용 |
|---|---|
| 누가 | 매장·브랜드명, 업종, 운영 형태(홀/포장/배달), 지역 |
| 무엇을 | 구체적인 방법 (할인 금액, 메뉴 구성, 채널, 횟수 등) |
| 결과 | 수치 (매출·리뷰·순위 등), 기간 |
| 근거 수준 | 공식 통계 / 기업 발표 / 사장님 본인 주장 / 플레이스 확인 사실 중 무엇인지 |
| 출처·날짜 | 기사·자료명과 날짜 |
| 우리 매장 적용 | 그대로 할 수 있는지, 바꿔야 하는지, 맞지 않는지(이유) |

**3. 실행 방법으로 나누기**
- **바로 할 수 있는 방법 (오늘~1주, 비용 거의 없음):** 대표님이 직접 하거나 세팅 첫 주에 끝나는 것 (예: 플레이스 '테이크아웃 할인' 등록, 쿠폰 1개 등록, 사진 추가, 대표키워드 수정, 소식 1개 발행)
- **적용할 수 있는 방법 (1–3개월, 월 제공 서비스 안에서):** 월관리 상품 항목과 연결해서 몇 개월 차에 무엇으로 할지 명시 (예: 체험단 15회로 '포장' 키워드 리뷰 쌓기, 인스타 기자단으로 숏폼 2회)
- 각 방법 옆에 근거가 된 사례 번호를 붙인다.

**4. 제안서 배치**
- '성공 사례 ① 매장', '성공 사례 ② 온라인' 슬라이드에 사례 표를 넣는다.
- 바로 이어서 '바로 할 수 있는 방법 / 적용할 수 있는 방법' 슬라이드를 둔다.
- 사례가 부족하거나 근거가 약하면 그렇다고 적고, 억지로 만들지 않는다.
6. 목표 수치는 상품 제공 수량에서 계산한 값만 쓰고, "예상치이며 보장이 아님"을 밝힌다.

## 상품 공통 사항 (대표님 확인)
- 모든 광고 상품에 **매월 기본 포함**: 네이버 광고(파워링크·플레이스·소상공인) 세부 세팅, 프로필 관리(구글·당근·카카오, 업종에 따라 다름), 플레이스 최적화, 리뷰 관리 등 플레이스 관리
- 이벤트 기획은 **대표님과 합의 후 진행**

## 젠스파크 크레딧 절약 순서
1. 원고(`slides.md`)를 먼저 만들고 대표님 확인을 받는다.
2. 확정된 원고로 젠스파크 생성은 업체당 1회만 한다.
3. 이후 수정(오타·숫자·문구·순서)은 내려받은 PPTX를 직접 고친다. 젠스파크를 다시 부르지 않는다.
4. 젠스파크를 다시 써야 하면 같은 작업에 이어서(`gsk task ask`), 바뀐 슬라이드만 보낸다.
5. 디자인이 확정된 덱은 다음 업체의 틀로 재사용한다.
