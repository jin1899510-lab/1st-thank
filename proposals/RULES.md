# 제안서 작성 규칙

대표님이 정한 규칙이다. 모든 제안서에 적용한다.

1. **가격은 맨 마지막 슬라이드에만** 넣는다. 표지·본문·다음 단계에는 금액을 쓰지 않는다.
2. **월 제공 서비스**는 노션 '외식업 광고 관리 상품 -수정중' 페이지에서 해당 상품의 항목과 수량을 그대로 가져와 별도 슬라이드로 보여 준다.
3. **설문지(고객 질문지) 내용은 넣지 않는다.** 구글폼 언급도 뺀다.
4. **추천은 사실에 근거한다.** 추천마다 출처(수집 데이터, 기사, 공식 자료)를 붙이고, 출처가 없는 의견은 넣지 않는다. 개인 주장이나 기업 발표는 그렇다고 밝힌다.
5. **성공 사례를 매번 조사해서 넣는다.** 같은 업종의 매장 사례(오프라인·포장·할인 등)와 온라인 마케팅 사례를 함께 넣고, 날짜와 출처를 표시한다. 자세한 방법은 아래 '성공 사례 분석 방법'을 따른다.

## 키워드별 검색 노출 조사 (모든 채널)
키워드 분석에서 나온 키워드(메인·세부·지역+업종·지역+제공내역)를 **하나씩 그대로 검색**해서 채널별로 세세하게 기록한다.

| 채널 | 확인 방법 | 기록할 것 |
|---|---|---|
| 네이버 플레이스 | 매장 좌표 기준 플레이스 목록, 애드로그 순위·히든 키워드 | 순위, 상위 10곳, 리뷰·사진·쿠폰·소식 |
| 네이버 통합검색 | 모바일 통합검색 결과 | 우리 매장·경쟁사 노출 여부, 블로그·카페 글 |
| 네이버 AI 브리핑 | 통합검색의 AI 브리핑 블록 | 브리핑이 뜨는지, 어떤 매장을 추천하는지 |
| 구글 지도 | `gsk maps-search` (구글 지도) | 매장 등록 여부, **상호·전화·영업시간이 네이버와 같은지**, 별점, 경쟁사 별점 |
| 구글·웹 검색 | `gsk search` | 상위 10개 결과(블로그·인스타·유튜브·다이닝코드 등)에 누가 나오는지 |
| AI 검색 | 젠스파크 등 AI 검색 답변 | 키워드로 물었을 때 추천에 우리 매장이 나오는지 |

- 키워드 × 채널 표로 정리하고, 우리 매장이 빠진 곳과 잘못 등록된 곳을 '바로 할 수 있는 방법'으로 연결한다.

## 플레이스·리뷰 분석 — 매장이 있는 업체 (애드로그 + 네이버 리뷰)
- 플레이스 링크가 있으면 `python tools/browser_collect.py place-analysis --slug <slug> --place-id <ID>` 로 우리 매장과 경쟁 매장(플레이스 상위)을 같이 분석한다. 에고라이트에 애드로그 로그인이 필요하다.
- 애드로그: 종합분석(추적 키워드별 순위·변동), 히든 키워드(매장이 잡히는 숨은 키워드), 최근 방문자 리뷰(날짜·유형: 영수증/예약/결제내역)
- 네이버 리뷰 화면: '이런 점이 좋았어요' 상위 키워드와 참여 수, 메뉴 언급 수, 특징(맛·서비스·가격·분위기 등) 언급 수
- 제안서에 넣을 것: 우리 vs 경쟁 매장 표(리뷰 수·최근 리뷰 속도·상위 키워드 순위·히든 키워드 수·리뷰 키워드), 경쟁 매장이 1위인 키워드 중 우리가 비어 있는 키워드, 리뷰에서 손님이 칭찬하는 점(→ 대표키워드·소식·광고 문구), 리뷰 유형 차이(예약 리뷰가 많으면 네이버 예약 세팅 제안)
- 순위는 애드로그가 추적하는 키워드 기준, 최근 리뷰 수는 애드로그 표본 기준이라고 밝힌다.

## 경쟁사 상세 조사 — 모든 업체 (2장)
경쟁사를 이름만 나열하지 않고, **어떻게 광고하고 어떤 이벤트로 손님을 끌어오는지**까지 세세하게 넣는다.
- 대상: 키워드 × 채널 조사에서 자주 나온 곳 4–7개 + 우리와 규모·이력이 비슷한 곳 1개 (오프라인 업체는 반경 안 플레이스 상위 매장)
- 수집: `python tools/browser_collect.py competitors --slug <slug> --keywords "..."` (파워링크 광고 문구·혜택 단어, 경쟁 매장 쿠폰·편의·소식) + `powercontents`(파워컨텐츠 광고주) + 유튜브·인스타·홈페이지는 검색으로 확인
- '경쟁사 상세 ①' 표: 경쟁사 × 채널 (파워링크 / 파워컨텐츠 / 플레이스 순위·리뷰 / 쿠폰·이벤트 / 소식 빈도 / 유튜브·인스타·홈페이지). 숫자는 '조사한 키워드 N개 중'처럼 범위를 밝힌다.
- 전환을 높이는 장치를 따로 적는다: 쿠폰(알림받기·저장 쿠폰, 시간대 쿠폰), 첫 방문·재방문 혜택, 리뷰 이벤트, 예약·톡톡·전화 버튼, 단체 예약 안내, 신메뉴·시즌 소식, 오픈 이벤트, 광고 문구의 혜택(무료 상담·24시·당일), 체크리스트·자료 받기 같은 상담 유도
- '경쟁사 상세 ②' 표: 경쟁사별 배울 것 / 하지 않을 것 / 우리 업체가 할 것. 바로 할 수 있는 방법·적용할 수 있는 방법 장과 연결한다.
- 효과(매출·상담 증가) 수치는 공개 자료가 없으면 '운영 방식만 확인'이라고 쓴다. 업종 규정(법률 광고, 의료광고 심의)에 걸리는 경쟁사 방식은 '하지 않을 것'에 둔다.

## 월별 실행 계획 · 월간 보고 — 모든 업체 (3장)
- '월별 실행 계획 ①': 첫 달을 주 단위로 (1주 정리·세팅 / 2주 광고 시작 / 3–4주 콘텐츠). 주별 수량을 더하면 월 제공 서비스 수량과 같아야 한다. 고객에게 받을 것(자료·검수·예산)도 주마다 적는다.
- '월별 실행 계획 ②': 12개월 로드맵 (1 / 2 / 3 / 4 / 5–6 / 7–9 / 10–12개월 차). 시작 월 가정을 적고 `[확인 필요]`. 업종 달력 일정(시즌·명절·법 시행일·선거·개학 등)을 출처와 함께 넣고, 각 일정이 몇 개월 차인지 맞춘다.
- '월간 보고서': 매달 같은 목차 — 한 장 요약, 광고(키워드별 노출·클릭·전환), 콘텐츠 발행 목록, 플레이스(순위·리뷰·쿠폰 사용), 이슈·이벤트 기록, 매달 같은 키워드 검색 화면 캡처(`capture`), 경쟁사 변화(`competitors` 다시 실행해 비교), 규정 변화(해당 업종), 다음 달 계획. 보고일·방식은 `[확인 필요]`.

## 파워컨텐츠 키워드 — 구매 가능 목록에서 고른다
- 파워컨텐츠는 네이버가 허용한 키워드에만 광고할 수 있다. 대표님이 준 구매 가능 목록(`tools/data/powercontents_keywords_*.csv`, 최신 파일 사용)에서 업체 업종·분야에 맞는 키워드를 골라 제안서에 넣는다.
- 순서: ① 업체 확인(업종·업무분야·지역) → ② 목록의 대분류·중분류(예: 전문서비스 > 법률)에서 분야 단어로 후보 추리기 → ③ 네이버 검색광고 API(`tools/naver_ad.py`)로 월간 검색수 → ④ 네이버 모바일 '브랜드 콘텐츠' 영역에서 지금 광고주 확인 → ⑤ 광고주가 없거나 적은 키워드부터 제안
- '파워컨텐츠 광고가 없다'를 기회로 쓰기 전에 그 키워드가 구매 가능 목록에 있는지 먼저 본다. 목록에 없으면 살 수 없어서 비어 있는 것이다 (법무법인 송에서 확인, 2026-11).
- 구매 불가 키워드는 파워링크·뉴스·칼럼으로 맡는다고 제안서에 나눠 적는다. 목록 업데이트 날짜를 출처에 적고, 세팅 전에 다시 확인한다고 쓴다.
- 의료 업종 키워드는 목록에 있어도 사전 심의 등 이슈가 있다 (목록 안내문).

## 이슈 대응 — 시기를 타는 업종이면 넣는다
- 검색 트렌드에서 법 시행·판결·선거·계절 같은 이슈 때 검색이 몰리면, '이슈 대응' 장을 넣는다: 지켜볼 소식, 이슈 때 한꺼번에 하는 일(파워링크 추가·칼럼·카드뉴스·파워컨텐츠·홈페이지), 미리 준비할 것, 대응 시간(고객과 정하기 전엔 `[확인 필요]`).
- 법률·병원처럼 검수가 필요한 업종은 검수 담당자 지정과 기본 원고 사전 검수를 함께 제안한다.

## 검색 트렌드 (구글 트렌드 · 네이버 데이터랩) — 모든 제안서에 넣는다
- 브라우저(ego-browser, Aside 등 대표님 PC 브라우저)로 **구글 트렌드**와 **네이버 데이터랩 검색어트렌드**를 조회해서 넣는다.
- 키워드: 업종·대표 메뉴·지역+업종 키워드 3–5개 묶음 (예: 연어덮밥, 간장새우, 한상차림, 장산역맛집)
- 조건: 최근 1년, 주간, 한국(구글) / PC+모바일 전체(네이버). 가능하면 엑셀·CSV로 받아 `data/trend_*.csv`에 저장
- 제안서에는 '검색 트렌드' 한 장: 1년 추세 그래프, 많이 찾는 시기(계절·요일), 1년 변화율, 관련 검색어·급상승 검색어
- 두 서비스 수치는 실제 검색 횟수가 아니라 기간 최고점을 100으로 둔 비교 값이라고 밝히고, 실제 검색량은 검색광고 수치(애드로그·검색광고 API)로 함께 쓴다.
- 클라우드 세션에서는 네이버 데이터랩·구글 트렌드가 막힌다(403·429, 2026-11 확인). 대표님 PC 브라우저가 연결돼 있지 않으면 위 조건을 적은 조회 요청문을 드리고 결과 파일을 받는다. 수치를 추정해서 채우지 않는다.

## 성공 사례 분석 방법
업종에 맞춰 세세하게 분석하고, 사례마다 **바로 할 수 있는 방법**과 **적용할 수 있는 방법**을 함께 정리한다.

**1. 조사 범위 (업종별로 좁혀서)**
- 같은 업종·같은 운영 형태 우선 (예: 족발 포장 전문 → 족발·보쌈 포장/배달 매장 → 포장 중심 외식업 순)
- 같은 상권(반경 1–3km) 상위 매장의 현재 운영 방식: 플레이스 쿠폰·소식·편의시설(테이크아웃 할인 등)·메뉴 구성·사진·배달앱 메뉴명
- 같은 업종 프랜차이즈·개인 매장의 기사, 공식 발표, 사장님 공개 사례
- 온라인: 리뷰·플레이스, 숏폼(인스타·유튜브), 당근, 맘카페, 배달앱 운영 사례
- 업종 특성 반영 (예: 외식업은 시즌 메뉴·포장/배달, 병원은 의료광고 심의 규정 안에서 가능한 것만)

**2. 사례마다 정리할 항목**
| 항목 | 내용 |
|---|---|
| 누가 | 매장·브랜드명, 업종, 운영 형태(홀/포장/배달), 지역 |
| 무엇을 | 구체적인 방법 (할인 금액, 메뉴 구성, 채널, 횟수 등) |
| 결과 | 수치 (매출·리뷰·순위 등), 기간 |
| 근거 수준 | 공식 통계 / 기업 발표 / 사장님 본인 주장 / 플레이스 확인 사실 중 무엇인지 |
| 출처·날짜 | 기사·자료명과 날짜 |
| 우리 매장 적용 | 그대로 할 수 있는지, 바꿔야 하는지, 맞지 않는지(이유) |

**3. 실행 방법으로 나누기**
- **바로 할 수 있는 방법 (오늘~1주, 비용 거의 없음):** 대표님이 직접 하거나 세팅 첫 주에 끝나는 것 (예: 플레이스 '테이크아웃 할인' 등록, 쿠폰 1개 등록, 사진 추가, 대표키워드 수정, 소식 1개 발행)
- **적용할 수 있는 방법 (1–3개월, 월 제공 서비스 안에서):** 월관리 상품 항목과 연결해서 몇 개월 차에 무엇으로 할지 명시 (예: 체험단 15회로 '포장' 키워드 리뷰 쌓기, 인스타 기자단으로 숏폼 2회)
- 각 방법 옆에 근거가 된 사례 번호를 붙인다.

**4. 제안서 배치**
- '성공 사례 ① 매장', '성공 사례 ② 온라인' 슬라이드에 사례 표를 넣는다.
- 바로 이어서 '바로 할 수 있는 방법 / 적용할 수 있는 방법' 슬라이드를 둔다.
- 사례가 부족하거나 근거가 약하면 그렇다고 적고, 억지로 만들지 않는다.
6. 목표 수치는 상품 제공 수량에서 계산한 값만 쓰고, "예상치이며 보장이 아님"을 밝힌다.

## 상품 공통 사항 (대표님 확인)
- 모든 광고 상품에 **매월 기본 포함**: 네이버 광고(파워링크·플레이스·소상공인) 세부 세팅, 프로필 관리(구글·당근·카카오, 업종에 따라 다름), 플레이스 최적화, 리뷰 관리 등 플레이스 관리
- 이벤트 기획은 **대표님과 합의 후 진행**
- **브랜드 블로그 = 파워컨텐츠 영역**이다. 제안서에는 '브랜드 블로그'라는 말을 쓰지 말고 **'파워컨텐츠'**로만 쓴다.

## 표현 규칙 (대표님 확인)
- 네이버 입찰가는 **매일 바뀌지 않는다.** "입찰가는 매일 바뀝니다" 같은 문구를 쓰지 않는다.
- **'상담 1건당 비용'은 쓰지 않는다.** 성과는 상담 신청 수·클릭 등으로 표현한다.
- 아직 광고를 시작하지 않은 업체는 검색·AI에 안 나오는 게 당연하다. "없음/미노출"로 지적하지 말고 **"세팅 예정", "이제 세팅합니다"**로 쓴다.

## 젠스파크 크레딧 절약 순서
1. 원고(`slides.md`)를 먼저 만들고 대표님 확인을 받는다.
2. 확정된 원고로 젠스파크 생성은 업체당 1회만 한다.
3. 이후 수정(오타·숫자·문구·순서)은 내려받은 PPTX를 직접 고친다. 젠스파크를 다시 부르지 않는다.
4. 젠스파크를 다시 써야 하면 같은 작업에 이어서(`gsk task ask`), 바뀐 슬라이드만 보낸다.
5. 디자인이 확정된 덱은 다음 업체의 틀로 재사용한다.
6. 필요하면 크레딧을 써도 된다 (대표님 허락). 다만 PPTX만 고치면 젠스파크 원본과 달라지므로, 대표님이 젠스파크 화면을 쓰는 경우에는 수정 사항을 모아 한 번에 젠스파크에도 반영한다.

## 업종별 추가 규칙
### 법률 (변호사·법무법인)
- 대한변협 광고 규정을 지킨다: '전관' 표현·공직 제복 사진·출신 비교 금지, 'OO센터' 등 주사무소·분사무소 외 명칭 금지, '전문'은 변협 전문분야 등록 시만, 승소율·'최고·유일'·무료·염가·'최저·원가·환불' 표현 금지. 경력은 사실 그대로만 쓴다. ('검사·판사 출신' 문구 금지안 검토 중 — 2026.06 보도, 진행 상황 확인)
- 블로그·기자단 등 제3자에게 맡긴 게시물도 변호사 광고에 포함된다. 모든 원고는 로펌 검수 후 게시한다고 제안서에 넣는다.
- 기업(사용자) 측 로펌이면 근로자 측 검색어(산재 보상, 부당해고 구제신청 등)를 제외 키워드로 제안한다.
- 경쟁 조사: 파워링크 광고주, '브랜드 콘텐츠'(파워컨텐츠) 영역 광고주, AI 브리핑 인용 출처, 구글 상위 로펌, 플레이스 상위 로펌.
- 예시: `proposals/song-law/`

### 병원
- 대표님이 병원 제안서에 따로 넣을 내용을 알려 주시면 여기에 추가한다. (아직 받지 않음)
- 그전까지 병원 작업이 들어오면, 시작 질문에 더해 "병원 제안서에 따로 넣을 내용이 있는지" 먼저 묻는다.
- 체험단·후기·전후 사진 등은 의료법상 의료광고 규정(심의 대상 여부 포함) 안에서만 제안한다.
