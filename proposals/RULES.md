# 제안서 작성 규칙

대표님이 정한 규칙이다. 모든 제안서에 적용한다.

1. **가격은 맨 마지막 슬라이드에만** 넣는다. 표지·본문·다음 단계에는 금액을 쓰지 않는다.
2. **월 제공 서비스**는 노션 '외식업 광고 관리 상품 -수정중' 페이지에서 해당 상품의 항목과 수량을 그대로 가져와 별도 슬라이드로 보여 준다.
3. **설문지(고객 질문지) 내용은 넣지 않는다.** 구글폼 언급도 뺀다.
4. **추천은 사실에 근거한다.** 추천마다 출처(수집 데이터, 기사, 공식 자료)를 붙이고, 출처가 없는 의견은 넣지 않는다. 개인 주장이나 기업 발표는 그렇다고 밝힌다.
5. **성공 사례를 매번 조사해서 넣는다.** 같은 업종의 매장 사례(오프라인·포장·할인 등)와 온라인 마케팅 사례를 함께 넣고, 날짜와 출처를 표시한다.
6. 목표 수치는 상품 제공 수량에서 계산한 값만 쓰고, "예상치이며 보장이 아님"을 밝힌다.

## 상품 공통 사항 (대표님 확인)
- 모든 광고 상품에 **매월 기본 포함**: 네이버 광고(파워링크·플레이스·소상공인) 세부 세팅, 프로필 관리(구글·당근·카카오, 업종에 따라 다름), 플레이스 최적화, 리뷰 관리 등 플레이스 관리
- 이벤트 기획은 **대표님과 합의 후 진행**

## 젠스파크 크레딧 절약 순서
1. 원고(`slides.md`)를 먼저 만들고 대표님 확인을 받는다.
2. 확정된 원고로 젠스파크 생성은 업체당 1회만 한다.
3. 이후 수정(오타·숫자·문구·순서)은 내려받은 PPTX를 직접 고친다. 젠스파크를 다시 부르지 않는다.
4. 젠스파크를 다시 써야 하면 같은 작업에 이어서(`gsk task ask`), 바뀐 슬라이드만 보낸다.
5. 디자인이 확정된 덱은 다음 업체의 틀로 재사용한다.
