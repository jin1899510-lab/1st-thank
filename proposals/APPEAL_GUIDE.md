# 소구점 분석 지침 (appeal_report.md 쓰는 법)

기획: `proposals/기획_경쟁사·소구점 분석.md` · 수집: `python tools/appeal.py --slug <slug> --place "<플레이스 링크>"`
읽을 자료: `proposals/<slug>/data/appeal/appeal_data.md`(요약) → `our.json`·`competitors.json`·`national.json`(리뷰 본문 `reviews`) → `data/area.md`(동 인구) → E드라이브 업체 폴더(정보뱅크·차별화 파일·사장님 질문지)

## 원칙
- 근거 없는 소구점은 쓰지 않는다. 모든 칭찬·강점에는 **숫자(리뷰 키워드 수·본문 횟수)나 인용(리뷰·소개글 원문, 매장 이름)**을 붙인다. 확인 안 된 건 🔶.
- 리뷰 인용은 짧게(한 문장 안), 맞춤법은 고치지 않는다. 손님 닉네임은 쓰지 않는다.
- 경쟁사 실명은 보고서(내부용)에는 쓰고, 손님에게 나가는 문장(카피·소개글)에는 쓰지 않는다. 비교·최상급·사실 왜곡 금지. 병원은 의료광고, 법률은 변협 규정.
- 표본 수를 밝힌다 (예: 리뷰 본문 최근 50개 중 12개).

## 보고서 구성 (8장)

### 1. 한 장 요약
- 우리 매장 한 줄 정체성(현재 손님이 느끼는 모습) → 핵심 소구점 1개 + 보조 2–4개 → 바로 할 것 3개

### 2. 우리 상권 유형·손님 상황
- 상권 유형 태그와 근거: 주변 시설(`area.facilities` 300m·500m 수), 동 인구(`area.md`: 1인 세대·세대당 인구·연령대), 교통
- 손님 상황(리뷰 표본): 방문 시간(점심/저녁), 목적(일상·데이트·친목·회식·여행), 동행(혼자·연인·가족·아이·친구), 대기·예약, 재방문 비율
- "우리 손님은 누구, 언제, 누구와, 왜" 3–4줄로 정리

### 3. 경쟁사 소구점 지도
경쟁사마다 카드 (키워드 상위 + 반경, 리뷰 수 많은 순):
| 항목 | 내용 |
|---|---|
| 왜 경쟁사인가 | `why` (키워드 순위·반경 거리) |
| 가게가 말하는 것 | 소개글·메뉴 이름·쿠폰·소식에서 내세우는 점 (원문 인용) |
| 손님이 말하는 것 | 리뷰 키워드 상위(수), 본문에서 반복되는 칭찬 2–3개 (인용) |
| 소구점 종류 | 맛·재료 / 양·가성비 / 가격 / 메뉴 구성(상차림·사이드) / 분위기·공간 / 서비스 / 편의(주차·예약·포장·혼밥·키즈) / 스토리·전문성 / 권위 |
| 전환 장치 | 쿠폰(알림받기·저장·시간대), 이벤트, 예약·주문, 단체 안내 |
| 약점 | 리뷰 본문의 아쉬움 (대기·가격·양·불친절·주차 등) |
그다음 표 하나로 모은다: 소구점 종류 × 매장 (●=내세움, ○=손님만 말함) → **다들 하는 것 / 아무도 안 하는데 손님이 원하는 것(빈자리)** 표시

### 3-1. 업종별 포인트 (기획서 2-2장)
- 업종 묶음의 '손님이 고르는 기준'을 먼저 적고, 그 기준으로 3장 카드를 본다
- 전문 업종(법률·세무·병원)은 '전문성 표현 기법' 표(자격 증명·경험 수치·사례 해설·과정 공개·대표자 이야기·제3자 권위·분야 세분화·교육·접근성)로 경쟁사 원문을 분류하고 ●/○, 잘 쓴 문장 3개·하지 말 문장 2개, 업종 규정 표시

### 4. 메뉴·가격·상차림 비교 (외식) / 서비스·가격 비교 (그 밖의 업종)
| 매장 | 대표 메뉴 (가격) | 1인 객단가 | 세트·코스·한상 | 상차림(기본 반찬·국·샐러드) | 사이드·서비스·리필 | 손님 반응 (리뷰) |
- 메뉴판 설명 + 리뷰 본문('반찬', '국', '샐러드', '리필', '서비스', '세트')에서 찾는다. 모르면 '-'
- 우리 가격 위치(낮음·중간·높음)와 그 이유를 한 줄로

### 5. 전국 사례와 접목 추천 (상권 맞춤)
- 전국 매장 중 **우리와 같은 상권 유형** 매장을 먼저, 그다음 리뷰가 많은 매장
- 방법마다: 무엇을 했나 → 왜 통했나(손님 상황) → 우리 상권에 그 손님 상황이 있나(근거) → 적합도 점수 → 우리 식으로 바꾼 모습
- 적합도 (각 5점, 25점 만점): 상권 일치 / 손님 일치(인구·리뷰 동행·연령) / 시간대·상황 일치 / 우리가 할 수 있나 / 비용·속도
  - 20점 이상 추천 · 13–19 바꿔서 추천 · 12 이하 제외(이유 한 줄)
- 바꾸는 방법: 핵심(손님이 좋아한 이유)만 남기고 우리 손님 상황에 맞게
| 추천 방법 | 배운 곳 (매장 · 지역 · 상권) | 왜 통했나 | 우리 상권에 맞나 (근거) | 우리 식으로 | 점수 | 언제 |

### 6. 우리 소구점 설계
1. 강점 후보 (최소 6개): 리뷰 칭찬(수), 메뉴·가격 차이, 상차림·사이드, 공간·편의, 사장님 이야기·경력(질문지·정보뱅크), 상권 타겟과의 맞음
2. 점수 (각 5점): 손님이 원하나 / 우리가 진짜 잘하나 / 경쟁사가 안 하나 / 말로 쉽게 전해지나 / 사진·콘텐츠로 보여 줄 수 있나
3. 경쟁사 소구점을 우리 것으로: 빌리기 / 쪼개기(우리 장면으로) / 뒤집기(경쟁사 약점 → 우리 강점) / 빈자리 차지 — 각각 예 1개 이상
4. 확정: **핵심 1개 (한 줄 정체성)** + 보조 2–4개 — 각각 근거 · 타겟 손님 상황 · 쓸 곳

### 7. 표현법·적용처
소구점마다:
- ① 한 줄 카피 (15자 안팎) 3안
- ② 설명 문장 — 손님이 궁금해할 '왜'를 풀어 준다 (외식업: 소리·식감·눈→코→입·먹는 법·장면·비유·한 줄 맺음 중 1–2개, 고급스럽고 친절한 말)
- ③ 손님 후기형 — 실제 리뷰 말투를 바탕으로 (지어낸 후기 아님, '이런 말을 듣는다' 형태)
- 쓰는 곳 예시: 플레이스 소개글 첫 줄 · 대표키워드 5개 · 메뉴 이름·설명 · 사진 첫 장 순서 · 소식 1개 · 쿠폰 문구 · 리뷰 답글 한 줄 · 파워링크 제목/설명 · 인스타 첫 문장 · 블로그 제목
- 금지: '대박·미쳤다·꿀팁', 최상급·비교, 효능, 사실 왜곡
