# 인터뷰 영상 → 캡컷 릴스 자동 생성

인터뷰 원본 영상을 넣으면 아래 결과가 **캡컷 프로젝트로 자동 저장**됩니다.

- **반복 정리**: 같은 말 반복, NG, 군말, 잡담을 잘라냅니다.
- **릴스 나누기**: 내용별로 **1분 미만 릴스**로 나누고, 릴스마다 타임라인 1개씩 만듭니다.
- **자막**: 질문은 **소제목**, 답변은 **귀여운 자막**으로 넣고, 주제별 색과 핵심 단어 강조를 적용합니다.
- **효과**: 첫 화면 **훅 문구**, 컷마다 번갈아 확대, 천천히 줌인, 글자 등장 애니메이션을 넣습니다.
- **타임라인 표**: 채팅에 보여주고, 엑셀용 파일로도 저장합니다.

## 도구별 역할

| 도구 | 하는 일 |
|---|---|
| 위스퍼(Whisper) | 음성을 단어 단위 시간이 붙은 텍스트로 바꿉니다 (`step2`) |
| 에프에프엠펙(FFmpeg) | 음성 추출, 장면 사진 추출, (선택) 기본 얼굴 보정 (`step1`) |
| 파이썬(Python) | 전체 실행과 캡컷 프로젝트 생성 (`step4`, `step5`) |
| 클로드 코드(Claude Code) | 대본을 읽고 반복 구간, 질문/답변, 릴스 구간, 훅, 강조 단어, 오타를 정해 `outline.json` 작성 (`step3`가 자막으로 변환) |
| 캡컷(CapCut) PC | 완성된 타임라인이 저장되는 곳. 열어서 확인하고, 다듬고, 내보내기 |

리모션(Remotion)은 이번 버전에서 쓰지 않습니다. Remotion으로 만든 그래픽은 영상에 박혀서 캡컷에서 글자를 고칠 수 없기 때문입니다. 그래서 효과는 모두 **캡컷 안에서 수정 가능한 방식**(텍스트 애니메이션, 키프레임 줌)으로 넣었습니다.

## 저장 구조

```
캡컷 프로젝트 목록
  한방장어_01편_전체      ← 반복을 잘라낸 전체 편집본
  한방장어_01편_릴스01    ← 1분 미만 릴스 (타임라인 1개)
  한방장어_01편_릴스02
  ...
작업 폴더 (config.json 의 work_root)
  D:/영상작업/한방장어/01편/
    audio.wav, frames/, transcript.txt/json, edit_plan.json, timeline.md/csv
```

> **업체 = 프로젝트 1개, 편 = 타임라인 1개 구조에 대해**
> 캡컷 한 프로젝트 안에 여러 타임라인을 넣는 파일 형식은 공개된 자료가 없습니다. 그래서 지금은 **이름 규칙(`업체_편_릴스번호`)으로 프로젝트를 나눠** 만듭니다.
> 타임라인이 2개 이상 들어 있는 캡컷 프로젝트 폴더를 하나 보내주시면, 그 구조를 분석해서 한 프로젝트 안에 넣도록 바꿀 수 있습니다.

## 설치 (Windows, 처음 한 번)

1. **파이썬 3.11** 설치
   - https://www.python.org/downloads/ 에서 받습니다.
   - 설치 첫 화면에서 **"Add python.exe to PATH"**를 꼭 체크하세요.
2. **FFmpeg** 설치
   - PowerShell을 열고 아래 명령을 실행합니다.
     ```
     winget install Gyan.FFmpeg
     ```
   - 설치가 끝나면 PowerShell을 닫았다가 다시 여세요.
3. **이 저장소를 PC로 받기**
   - GitHub에서 `claude/pensive-planck-lweb7k` 브랜치를 ZIP으로 받아 압축을 풀거나, `git clone`으로 받습니다.
4. **필요한 패키지 설치**: 저장소 폴더에서 실행합니다.
   ```
   pip install -r pipeline/requirements.txt
   ```
5. **설정 파일 만들기**
   - `pipeline/config.example.json`을 복사해서 `pipeline/config.json`을 만듭니다.
   - `capcut_draft_dir`: 캡컷 프로젝트 저장 위치를 적습니다. 캡컷 → 설정 → 프로젝트(초안) 위치에서 확인할 수 있습니다. 보통 이 경로입니다.
     `C:/Users/<사용자이름>/AppData/Local/CapCut/User Data/Projects/com.lveditor.draft`
   - `work_root`: 작업 파일을 모아둘 폴더를 적습니다. 예: `D:/영상작업`
6. **(권장) 캡컷 자동 업데이트 끄기**: 캡컷이 업데이트되면 프로젝트 파일 형식이 바뀌어 자동 생성이 멈출 수 있습니다.

### 그래픽카드 관련
- Whisper(faster-whisper)는 **NVIDIA 그래픽카드에서만** 빨라집니다. AMD나 인텔 그래픽은 **CPU로** 돌아갑니다. 정상 작동은 하지만 시간이 걸립니다.
- 대략 **영상 길이와 비슷하거나 더 오래** 걸릴 수 있습니다.
- 너무 느리면 `config.json`의 `whisper.model`을 `medium`이나 `small`로 바꾸세요. 빨라지는 대신 정확도가 조금 떨어집니다.
- 모델은 처음 실행할 때 자동으로 내려받습니다. 수백 MB에서 1.5GB 정도입니다.

## 사용법

### 작업 화면으로 하기 (추천)

저장소 폴더의 **`캡컷_자동편집.bat`**을 더블클릭하면 작업 화면이 열립니다.

1. **폴더 설정**: 캡컷 프로젝트 폴더와 작업 폴더를 확인합니다. 처음 한 번만 하면 됩니다.
2. **업체 이름**을 적고, **파일 추가** 또는 **폴더 추가**로 영상을 넣습니다.
   - 편 이름을 비워 두면 01편, 02편… 순서로 자동으로 붙습니다.
   - 편 이름을 바꾸려면 목록에서 더블클릭합니다.
3. **작업 방식**을 고릅니다.
   - 전체본, 릴스 최대 길이, 훅 문구, 얼굴 기본 보정
   - 확대·줌인 효과, 글자 애니메이션, 음성 인식 정확도
   - Claude에게 추가로 요청할 내용
4. **▶ 실행**을 누릅니다. 5단계가 차례로 진행되고, 끝나면 캡컷 프로젝트 목록에 바로 저장됩니다.
   - 3단계(편집 계획)는 PC에 설치된 Claude Code(`claude -p`)가 대본을 읽고 작성합니다.
   - 캡컷이 켜져 있으면 4단계에서 기다렸다가, 캡컷을 닫으면 자동으로 이어서 저장합니다.
   - 고친 뒤 다시 만들 때는 '실행할 단계'에서 4, 5만 체크하면 빠릅니다.

### 가장 쉬운 방법: Claude Code에게 맡기기

저장소 폴더에서 Claude Code를 열고 이렇게 말하면 됩니다.

```
한방장어 01편 처리해줘. 영상은 D:/원본/20260923_141411.mp4 야.
```

`.claude/skills/interview-shorts` 스킬이 위 순서를 자동으로 진행합니다. 대본을 읽고 편집 계획을 세우는 일도 Claude Code가 합니다.

### 직접 실행할 때 (`pipeline` 폴더에서)

```
python step1_prepare.py    --client 한방장어 --episode 01편 --video "D:/원본/20260923_141411.mp4"
python step2_transcribe.py --client 한방장어 --episode 01편
#  → Claude Code가 transcript.txt 를 읽고 outline.json 작성
python step3_make_plan.py   --client 한방장어 --episode 01편   # 자막 자동 분할 + 침묵 자르기
python step4_build_capcut.py --client 한방장어 --episode 01편          # 캡컷을 끈 상태에서
python step5_timeline.py     --client 한방장어 --episode 01편
```

| 옵션 | 설명 |
|---|---|
| `step1 --beauty` | FFmpeg 기본 보정본(피부결, 밝기, 채도)을 만들어 편집에 사용합니다. 화면 전체에 적용되고 오래 걸립니다 |
| `step4 --only 릴스01` | 하나만 만듭니다. 처음 스타일을 확인할 때 쓰세요 |
| `step4 --replace` | 같은 이름의 캡컷 프로젝트를 덮어씁니다 |
| `step4 --media-path` | 다른 컴퓨터에서 만든 프로젝트를 이 PC에서 열 때, 이 PC의 영상 경로를 지정합니다 |

### 스타일과 효과 바꾸기 (`config.json`)
- `style.question` / `style.answer` / `style.hook`: 글자 크기, 색, 테두리, 위치. `position_y` 값은 위가 +, 아래가 −입니다.
- `topic_palette`: 주제별 색. 순서대로 적용됩니다.
- `effects`
  - `punch_in_zoom`: 컷마다 번갈아 확대하는 비율
  - `slow_zoom`: 천천히 줌인하는 비율
  - `hook_seconds`: 훅 문구가 나오는 시간(초)
  - `*_intro`: 글자 등장 애니메이션 이름
  - `video_intro`: 첫 컷 등장 애니메이션 이름
  - 쓰지 않을 효과는 `null`로 둡니다.
- `reel_max_seconds`: 릴스 최대 길이(기본 59초)

## 주의할 점
- **캡컷을 끈 상태에서** `step4`를 실행하세요. 켜져 있으면 캡컷의 자동 저장이 덮어쓸 수 있습니다.
- 캡컷은 외부 프로그램용 공식 연동 기능이 없어서, 커뮤니티 라이브러리 **pycapcut**으로 프로젝트 파일을 만듭니다. 캡컷이 업데이트되면 안 열릴 수 있습니다.
- **효과 때문에 프로젝트가 안 열리면** `config.json`에서 그 효과를 `null`로 바꾸고 `--replace`로 다시 만드세요.
- **얼굴 슬림이나 다크서클 같은 정밀 보정**은 캡컷 리터치에서 하세요. 클립을 선택한 뒤 "모두 적용"을 누르면 됩니다.
