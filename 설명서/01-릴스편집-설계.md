# 01-릴스편집 설계

02-인스타분석에서 받은 원고 + 스타일 설명서로 릴스를 만들어 캡컷 프로젝트로 저장한다.
캡컷 저장은 사장님 PC에서 실행한다 (클라우드에서는 PC의 캡컷 폴더에 쓸 수 없음).

## 진행 순서
1. 계획: 원고를 문장별로 나누고 장면·효과·모션그래픽·GIF·효과음 선택. 여러 편이면 겹치지 않게 분배
2. 목소리: 일레븐랩스
3. 조립: 자막(한 줄 6~15자), 장면 보정, 손님 얼굴 모자이크, 음식 PIP, 초반 3초 훅, 효과 정리, 음량 맞춤, 배경음악
4. 캡컷 저장: 편마다 프로젝트 하나 + 썸네일 커버
5. 점검: 컷별 스토리보드 이미지 확인 → 안 맞는 장면 수정 후 다시 저장

## 일레븐랩스 목소리
- 고를 수 있는 목소리: 내 계정 목소리(직접 만든 목소리 포함) + 공개 목소리 중 한국어
- 미리 듣기로 고르고, 가게별로 `고객설정\가게이름\음성설정.json`에 저장
- 다국어 모델 사용, 발음 사전(투뿔, 마산녁 등) + 숫자 읽는 법 변환
- 목표 길이에 맞춰 속도 0.7~1.2배, 넘치면 원고 줄이기 안내
- API 키는 고객설정 폴더에 보관

## 캡컷 저장
- 사장님 캡컷에서 만든 빈 프로젝트를 "틀"로 사용해 그 버전 형식으로 타임라인 작성
- 트랙: 영상 / PIP / 나레이션 / 배경음악 / 효과음 / 자막
- 프로젝트 이름: `가게이름_날짜_01편`
- 프로젝트 파일이 암호화된 버전이면 대체 방법: 완성 mp4 + 자막 srt + 소스 폴더
