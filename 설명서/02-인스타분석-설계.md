# 02-인스타분석 설계

키워드로 인스타 인기 릴스를 찾아 분석하고, 사장님이 고른 스타일로 업체 원고를 만든다.
결과(원고 + 스타일 설명서)는 01-릴스편집으로 넘긴다.

## 진행 순서
1. 분석할 인스타 계정 아이디 1개 입력
2. Apify(apify/instagram-reel-scraper)로 그 계정 릴스를 최신순으로 가져와 반응 좋은 릴스 선택
3. 분석: 제목, 장면, 훅, 전환, 훅 문구, 화면 글자와 위치, 원고 스타일, 원고 외 음성
4. 카드 화면으로 정리 (썸네일 + 한 줄 요약 + 화면 형태·글꼴·컷 길이)
5. 사장님이 카드 체크
6. 업체 내용 + 셀링포인트 → 체크한 스타일의 원고로 변환 (내용은 지어내지 않음)

## 인기 순위 기준
- 조회수·좋아요·댓글은 Apify가 준다. 공유 수는 Apify 유료 요금제에서 `--shares` 로 가져온다.
- 저장 수는 Apify도 주지 않는다.

## 폴더 구조
```
plugins/02-인스타분석/
├── .claude-plugin/plugin.json
├── skills/insta-analysis/SKILL.md
├── scripts/
│   ├── fetch_reels.py     계정 아이디 → 최신 릴스 (Apify)  ✅ 완료
│   ├── analyze_video.py   컷 감지(ffmpeg), 장면 캡처, 글자·위치(OCR), 받아쓰기(Whisper)
│   └── make_cards.py      카드 화면(HTML)
└── templates/
    ├── 분석항목.md
    ├── 스타일카드.json
    └── 원고변환규칙.md
```

## 필요한 것
- Apify 계정과 API 토큰 (환경변수 `APIFY_TOKEN`)
- 비용: 릴스 1개당 약 0.0026달러 (무료 요금제 기준, 100개 ≈ 0.26달러)
- 결과·토큰은 저장소 밖: `C:\작업\고객설정\가게이름\`

## 규칙
- 쉬운 말, 숫자는 표로
- 남의 영상은 분석용으로만 사용, 그대로 베끼지 않음
