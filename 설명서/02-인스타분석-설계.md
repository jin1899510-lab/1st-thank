# 02-인스타분석 설계

키워드로 인스타 인기 릴스를 찾아 분석하고, 사장님이 고른 스타일로 업체 원고를 만든다.
결과(원고 + 스타일 설명서)는 01-릴스편집으로 넘긴다.

## 진행 순서
1. 키워드 5개 이상 입력 (링크 직접 입력은 하지 않음 — 키워드만)
2. 키워드마다 인기 릴스 2개 자동 선택
3. 분석: 제목, 장면, 훅, 전환, 훅 문구, 화면 글자와 위치, 원고 스타일, 원고 외 음성
4. 카드 화면으로 정리 (썸네일 + 한 줄 요약 + 화면 형태·글꼴·컷 길이)
5. 사장님이 카드 체크
6. 업체 내용 + 셀링포인트 → 체크한 스타일의 원고로 변환 (내용은 지어내지 않음)

## 인기 순위 기준
- 다른 계정의 저장·공유 수는 인스타 API가 주지 않는다.
- 점수 = 조회수(있으면) + 댓글×3 + 좋아요. 최근 30일 게시물 우선.

## 폴더 구조
```
plugins/02-인스타분석/
├── .claude-plugin/plugin.json
├── skills/insta-analysis/SKILL.md
├── scripts/
│   ├── collect.py         키워드(해시태그) → 인기 릴스 수집·점수
│   ├── download.py        영상·캡션 받기
│   ├── analyze_video.py   컷 감지(ffmpeg), 장면 캡처, 글자·위치(OCR), 받아쓰기(Whisper)
│   └── make_cards.py      카드 화면(HTML)
└── templates/
    ├── 분석항목.md
    ├── 스타일카드.json
    └── 원고변환규칙.md
```

## 필요한 것
- 인스타 크리에이터 계정이 페이스북 페이지에 연결되어 있어야 함
- 메타 토큰 권한: instagram_basic, pages_show_list, pages_read_engagement
  (해시태그 검색은 7일에 30개 해시태그까지)
- 결과·토큰은 저장소 밖: `C:\작업\고객설정\가게이름\`

## 규칙
- 쉬운 말, 숫자는 표로
- 남의 영상은 분석용으로만 사용, 그대로 베끼지 않음
