# 안티그래비티에서 인스타 연결 방식 확인하기

목적: 릴스 스튜디오(예시 프로그램)가 인스타 자료를 어떻게 가져오는지 알아내서,
02-인스타분석에 같은 방식을 쓸 수 있는지 정한다.

## 1단계. 안티그래비티 열기
1. 안티그래비티 실행
2. File → Open Folder → 릴스 스튜디오 코드가 있는 폴더 선택
3. 오른쪽 에이전트(대화) 창 열기

## 2단계. 아래 내용을 그대로 복사해서 붙여넣기

```
이 폴더의 프로그램이 인스타그램 자료(릴스 영상, 조회수, 좋아요, 댓글, 캡션 등)를
어떻게 가져오는지 조사해서 보고서를 만들어줘. 코드는 고치지 마.

중요: 토큰, 비밀번호, API 키, 쿠키의 "값"은 절대 보고서에 쓰지 마.
값 대신 "있음/없음"과 "어느 파일의 어떤 이름(변수명)인지"만 적어줘.

조사할 것:
1. 인스타 자료를 가져오는 방식 (해당하는 것 모두)
   - 공식 API (graph.facebook.com 또는 graph.instagram.com)
   - 다운로드 프로그램 (yt-dlp, instaloader 등)
   - 브라우저 자동화 (playwright, selenium, puppeteer, 안티그래비티 브라우저)
   - 기타
2. 방식별로 관련 파일 경로와 함수 이름
3. 로그인 정보가 어디 저장되는지 (.env, 설정 파일, 브라우저 쿠키 등) — 값은 쓰지 말 것
4. 공식 API를 쓴다면:
   - 사용하는 주소(엔드포인트) 목록
   - 토큰 종류 (사용자 토큰 / 페이지 토큰 / 시스템 사용자 토큰)
   - 가능하면 토큰 권한 목록을 조회해서 적기
     (graph.facebook.com/me/permissions 결과의 권한 "이름"만)
   - 연결된 인스타 계정 종류 (크리에이터 / 비즈니스)
5. 키워드(해시태그)로 검색하는 기능이 있는지, 있다면 어떻게 하는지
6. 가져오는 숫자 항목: 조회수 / 좋아요 / 댓글 / 저장 / 공유 중 무엇을 가져오는지,
   내 게시물만인지 남의 게시물도인지
7. 영상 분석(컷 길이, 글꼴, 자막 위치 등)은 어떤 라이브러리로 하는지
   (ffmpeg, OCR, whisper, AI 모델 등)
8. 필요한 프로그램과 버전 (requirements.txt, package.json 등)

결과는 이 폴더에 "인스타연결_조사결과.md" 파일로 저장해줘.
마지막에 값(토큰·비밀번호)이 들어가지 않았는지 한 번 더 확인해줘.
```

## 3단계. 결과 확인
1. 안티그래비티가 만든 `인스타연결_조사결과.md` 를 연다.
2. 아래 같은 긴 문자열이 보이면 지우기 (토큰일 수 있음)
   - `EAA...` 로 시작하는 문자열 (메타 토큰)
   - `IGQ...` 로 시작하는 문자열 (인스타 토큰)
   - `sessionid=` 뒤의 값 (인스타 로그인 쿠키)
3. 확인이 끝나면 파일 내용 전체를 Claude 대화창에 붙여넣기

## 4단계. Claude가 할 일 (결과를 받은 뒤)
| 조사 결과 | 다음 작업 |
|---|---|
| 공식 API 토큰 사용 | 같은 권한의 토큰을 이 환경 비밀값 또는 `C:\작업\고객설정`에 두고 collect.py에서 사용 |
| 다운로드 프로그램 / 브라우저 자동화 | 같은 방식을 쓸지 함께 결정. 쓴다면 사장님 PC에서 실행하는 구조로, 하루 수집량 제한을 둠 (계정 차단 방지) |
| 여러 방식 혼합 | 키워드 검색은 공식 API, 영상 받기는 다운로드 프로그램처럼 나눠서 설계 |

## 주의
- 토큰·비밀번호·쿠키 값은 대화창, 저장소, 설명서 어디에도 붙이지 않는다.
- 브라우저 자동화·다운로드 방식은 인스타 약관상 회색 지대라 많이 돌리면 계정이 막힐 수 있다.
