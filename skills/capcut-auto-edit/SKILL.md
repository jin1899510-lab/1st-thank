# 캡컷 자동 편집

사용자의 Windows PC에 설치된 **캡컷 데스크톱**을 컴퓨터 사용 도구로 직접 조작해 숏폼(9:16) 영상을 만든다.
사용자는 비개발자이며 한국어로 소통한다. 설명과 질문, 보고는 모두 쉬운 한국어로 한다.

## 0. 시작 전 확인

1. **컴퓨터 사용 도구가 있는지 확인한다.** 도구 이름은 `mcp__computer-use__*` 또는 `mcp__remote-devices__computer_*`이다.
   - 없으면 작업을 흉내 내지 말고, 아래 내용을 안내한 뒤 멈춘다.
     - Claude 데스크톱 앱의 **새 채팅(또는 Cowork)**에서 실행해야 한다.
     - 설정에서 **컴퓨터 사용(Computer use)**을 켜야 한다.
   - Claude Code 클라우드 세션에서는 PC 화면을 조작할 수 없다.
2. **CapCut 사용 권한을 요청**하고 사용자의 승인을 기다린다.
3. **스크린샷으로 실제 화면을 먼저 확인**한다. 캡컷은 버전마다 메뉴 이름과 위치가 다르다.
   - 아래에 적힌 메뉴 이름(리터치, 자동 캡션 등)은 예시일 뿐이다. 화면에 보이는 실제 이름을 따른다.
4. **모드를 정한다.**
   - 사용자가 원고를 주면 → **원고형(A)**
   - 인터뷰 또는 대화 영상이면 → **인터뷰형(B)**
   - 애매하면 사용자에게 물어본다.
5. **영상이 길면**(대략 3분 이상) 앞부분 1분만 먼저 작업해서 스타일을 확인받은 뒤 전체를 진행하자고 제안한다. 화면을 하나씩 클릭하는 방식이라 오래 걸리기 때문이다.

공통 원칙:
- **원본은 건드리지 않는다.** 원본 프로젝트는 확인만 하고, 편집은 항상 **새 프로젝트(9:16)**에서 한다.
- **결제와 업로드는 사용자에게 맡긴다.** 유료(Pro) 기능의 결제, 계정 설정 변경, 외부 업로드는 하지 않는다. 필요하면 사용자에게 알린다.
- **내보내기 전에는 결과를 보여주고 확인받는다.**

## A. 원고형: 원고 자막 + 영상 배치 (음성 없음)

1. **소스 파악**: 지정된 프로젝트(예: '한방장어')를 열고, 미디어의 영상을 하나씩 재생하거나 훑어본다. 그리고 이렇게 정리한다.
   - `클립명 | 길이 | 장면 설명 | 쓸 만한 구간(초)`
   - 장면 설명 예시: 장어 굽는 장면, 한상 차림, 매장 외관
2. **새 프로젝트**: 9:16 비율로 새 프로젝트를 만든다.
3. **자막**: 원고를 문장 단위로 나눠 텍스트 자막으로 넣는다.
   - 음성이 없으므로 화면에 머무는 시간은 글자 수 기준으로 문장당 2~4초를 준다. 대략 초당 5~6글자이고, 최소 2초, 최대 4초다.
   - 세로 화면이라 한 줄은 15자 안팎으로 끊는다.
4. **배치**: 문장마다 내용에 가장 잘 맞는 클립 구간을 골라, 자막 길이에 맞게 잘라 배치한다.
   - 같은 구간을 연달아 반복하지 않는다.
   - 화면을 9:16에 맞게 채운다. 핵심 피사체가 중앙에 오게 한다.
5. **확인**: 결과를 보여주고 확인받는다.
6. **타임라인 보고**: 아래 "타임라인 보고" 형식으로 보고한다.

## B. 인터뷰형: 얼굴 보정 + 질문 소제목 + 귀여운 자막

1. **영상 파악**: 인터뷰 영상을 확인해서 인터뷰어 **질문 구간**과 **답변 구간**을 구분한다.
2. **새 프로젝트**: 9:16으로 새 프로젝트를 만들고 영상을 넣은 뒤, 인물 얼굴이 화면 중앙에 오도록 위치와 크기를 맞춘다.
3. **얼굴 보정**: 클립을 선택하고 비디오 탭의 리터치(뷰티) 메뉴에서 자연스럽게 보정한다. 인터뷰는 신뢰감이 중요하므로 과하게 하지 않는다.
   - 피부 매끄럽게 20~30
   - 화이트닝 10~20
   - 다크서클 20~40
   - 얼굴 슬림 5~15. 과하면 배경이 휘어 보인다.
   - 조정: 밝기 +5~10, 채도 +5
4. **자막 생성**: 자동 캡션(한국어)으로 자막을 만들고, 잘못 인식된 단어를 고친다. 고친 내용은 기록해 둔다.
5. **자막 스타일 2종**
   - **질문 → 소제목**: 크고 굵게, 화면 상단에 둔다. 질문을 짧게 요약한다. 예: `Q. 한방장어 시작한 계기는?`
   - **답변 → 귀여운 일반 자막**: 둥근 폰트, 파스텔 색, 흰 테두리로 화면 하단에 둔다. 말투는 살리고 짧게 끊는다.
   - **같은 종류끼리 스타일을 일괄 적용**해서, 사용자가 나중에 한 번에 전체 수정할 수 있게 한다. 캡컷의 '모든 자막에 적용' 같은 기능을 쓰거나, 종류별로 트랙을 분리한다.
6. **주제 구분**
   - 질문(주제)이 바뀔 때마다 소제목 색을 바꾼다. 주제마다 색 1개를 정한다.
   - 답변 속 핵심 단어(예: 한방, 장어, 보양)는 그 주제의 색으로 강조한다.
7. **확인**: 결과를 보여주고 확인받는다.
8. **타임라인 보고**: 아래 형식으로 보고한다.

## 타임라인 보고 (모든 작업이 끝난 뒤 마지막에)

영상 처음부터 끝까지 빠짐없이 표로 작성한다.
사용자가 엑셀이나 메모장에 붙여넣기 쉽도록 마크다운 표로 만든다.

**원고형**

| 시작~끝 (00:00:00) | 자막 | 사용한 영상 · 구간 |
|---|---|---|

**인터뷰형**

| 시작~끝 (00:00:00) | 구분 (질문/답변) | 원고 (자막 문장 그대로) | 주제 | 자막 스타일 · 색 |
|---|---|---|---|---|

표 아래에 요약을 붙인다.
- 전체 영상 길이
- 주제(질문) 목록과 각 주제의 시작 시간 (인터뷰형)
- 주제별로 사용한 색상 (인터뷰형)
- 적용한 얼굴 보정과 조정 값 (인터뷰형)
- 자동 캡션에서 고친 단어 목록 `원래 → 수정` (인터뷰형)
- 사용자가 직접 확인하거나 결정해야 할 것 (예: Pro 기능 사용 여부, 애매했던 구간)

## 막혔을 때

- **메뉴를 못 찾을 때**: 스크린샷으로 다시 확인한다. 그래도 없으면 버전 차이일 수 있으니, 사용자에게 화면을 설명하고 물어본다.
- **작업이 오래 걸릴 때**: 진행 상황을 짧게 알린다. 예: "자막 20/45개 완료"
- **판단이 애매할 때**: 질문인지 답변인지 헷갈리거나, 어울리는 장면이 없을 때는 추측하지 말고 후보를 제시해 질문한다.
