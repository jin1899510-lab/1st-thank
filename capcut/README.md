# 캡컷 자동 편집 지침 모음

캡컷 PC(Windows)에서 Claude가 직접 편집하도록 맡길 때 쓰는 지침입니다.

## 0. 준비 (최초 1회)

1. **Claude 데스크톱 앱**(Windows)을 설치하고 로그인합니다.
2. 앱 **설정 → 컴퓨터 사용(Computer use)**을 켭니다.
3. 작업할 때마다:
   - 캡컷 PC를 실행해 둡니다.
   - 데스크톱 앱에서 **새 채팅(또는 Cowork)**을 엽니다. Claude Code 메뉴에서는 안 됩니다.
   - 아래 지침 중 하나를 붙여넣습니다.
   - **"CapCut 사용 허용"** 창이 뜨면 허용합니다.
   - 작업 중에는 마우스와 키보드를 건드리지 않습니다.

> Claude Code(claude.ai/code) 클라우드 세션에서는 PC 화면을 조작할 수 없습니다. 캡컷 작업은 꼭 데스크톱 앱 새 채팅에서 하세요.

---

## 지침 A. 원고형: 원고 + 한방장어 영상 배치 (음성 없음)

```
캡컷 PC에서 작업해줘.
1) 캡컷의 '한방장어' 프로젝트를 열어서 안에 있는 영상들을 하나씩 확인하고, 어떤 장면인지 정리해줘.
2) 9:16 비율로 새 프로젝트를 만들어줘.
3) 아래 원고를 문장 단위 자막으로 넣어줘. 음성은 없으니 글자 수에 맞춰 문장당 2~4초로 배분해줘.
4) 각 자막 내용에 가장 잘 맞는 '한방장어' 영상 구간을 골라 자막 길이에 맞게 배치해줘.
5) 모든 작업이 끝나면 [시작~끝 시간 | 자막 | 사용한 영상·구간] 표로 타임라인을 정리해서 보내줘.
작업 전에 캡컷 사용 권한을 요청하고, 애매한 부분은 질문해줘.

[원고]
(여기에 원고 붙여넣기)
```

---

## 지침 B. 인터뷰형: 얼굴 보정 + 질문 소제목 + 귀여운 자막 + 타임라인

```
캡컷 PC에서 직접 작업해줘. 작업 전에 캡컷 사용 권한을 요청하고, 애매한 부분은 질문해줘.

[대상] 캡컷 '한방장어' 프로젝트의 인터뷰 영상 (파일명: ________)

1) 영상 파악
 - 프로젝트를 열고 영상을 확인해서, 인터뷰어 질문 구간과 답변 구간이 어디인지 정리해줘.

2) 새 프로젝트 (9:16)
 - 9:16 비율로 새 프로젝트를 만들고, 인터뷰 영상을 넣어서 인물 얼굴이 화면 중앙에 오도록 맞춰줘.

3) 얼굴 보정 (비디오 탭 > 리터치)
 - 자연스럽게: 피부 매끄럽게 20~30, 화이트닝 10~20, 다크서클 20~40, 얼굴 슬림 5~15
 - 조정: 밝기 +5~10, 채도 +5

4) 자막 생성
 - 텍스트 > 자동 캡션(한국어)으로 자막을 만들고, 잘못 인식된 단어는 고쳐줘.

5) 자막 스타일 2종
 - 질문 구간: '소제목' 스타일 (크고 굵게, 화면 상단, 질문을 짧게 요약. 예: "Q. 한방장어 시작한 계기는?")
 - 답변 구간: '귀여운' 일반 자막 (둥근 폰트, 파스텔 색, 흰 테두리, 화면 하단)
 - 같은 종류끼리는 스타일을 일괄 적용해서, 나중에 한 번에 전체 수정할 수 있게 해줘.

6) 주제 구분
 - 질문(주제)이 바뀔 때마다 소제목 색을 다르게 해서 구분되게 해줘.
 - 답변 속 핵심 단어(예: 한방, 장어, 보양 등)는 그 주제 색으로 강조해줘.

7) 내보내기 전에 결과를 보여주고 확인받아줘.

8) 모든 작업이 끝나면, 마지막으로 타임라인을 채팅에 정리해서 보내줘.
 - 아래 표 형식으로, 영상 처음부터 끝까지 빠짐없이 작성해줘.
   | 시작~끝 시간 (00:00:00) | 구분 (질문/답변) | 원고 (자막 문장 그대로) | 주제 | 자막 스타일·색 |
 - 표 아래에 요약도 붙여줘:
   · 전체 영상 길이
   · 주제(질문) 목록과 각 주제의 시작 시간
   · 주제별로 사용한 색상
   · 적용한 얼굴 보정·조정 값
   · 자동 캡션에서 고친 단어 목록 (원래 → 수정)
 - 표는 복사해서 엑셀이나 메모장에 붙여넣기 쉽게 만들어줘.
```

---

## 팁

- 영상이 길면 지침 끝에 **"앞부분 1분만 먼저 해보고 보여줘"**를 붙여 스타일을 먼저 확인하세요.
- 수정은 같은 채팅에서 바로 요청하면 됩니다. 예: "소제목 더 크게", "자막 색 분홍으로 통일"
- 얼굴 보정은 자연스러움이 우선입니다. 추천 값보다 높이면 보정한 티가 납니다.
- **Pro** 표시가 붙은 기능은 내보낼 때 결제 안내가 뜰 수 있습니다.
